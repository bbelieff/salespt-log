# 경영일지앱 시연 시나리오 대본 — 졸업생 총회용

> **📄 이 문서는 무엇인가요?**
> - **한 줄 요약**: 졸업생 총회에서 연습기(테스트) 구글시트로 "영업의 한바퀴(컨택→미팅→계약→수납)"를 라이브 시연하기 위한 단계별 대본.
> - **누가 읽나요**: 발표자(시연 진행자)
> - **읽고 나면 알 수 있는 것**: 어떤 화면을 어떤 순서로 누르고, 무엇을 입력하고, 무슨 멘트를 할지
> - **시연 소요**: 메인 시나리오 약 5~7분 (전체 세션 20분 중)

---

## 0. 시연 전 사전 준비 (발표 시작 30분 전 체크)

발표 당일 당황하지 않으려면 **미리 한 번 똑같이 돌려보세요.** 이게 가장 중요합니다.

- [ ] **연습기 구글시트가 앱에 연결돼 있는지 확인** — 연습기 전용 계정으로 로그인 → 시트 데이터가 화면에 뜨는지 확인
- [ ] **연습기 시트 초기화** — 시연을 "빈 상태에서 채워나가는" 모습으로 보여주려면, 시연용 날짜(아래 예시 = 6월 12일 전후)의 행이 비어 있어야 함. 이미 데이터가 차 있으면 깔끔한 날짜를 하나 골라 두기
- [ ] **인터넷·화면 미러링(빔/TV) 확인** — 모바일 화면을 띄울지 PC 화면을 띄울지 정하기
- [ ] **로그인 미리 해두기** — 구글 로그인은 시연 중에 하면 끊길 수 있으니 미리 로그인 상태로
- [ ] **글씨 크게** — PC라면 브라우저 확대(Ctrl + `+`)로 뒷자리도 보이게

> 💡 **권장 화면**: 모바일은 "입력이 얼마나 간단한지"를, PC는 "대시보드가 얼마나 한눈에 보이는지"를 잘 보여줍니다.
> 시간이 짧으면 **모바일 하나로 입력 → 마지막에 PC 대시보드 한 번**이 가장 임팩트 있어요.

---

## 시나리오 A (메인) — 영업의 한바퀴: 컨택 → 미팅 → 계약 → 수납

> **이 시나리오의 의미**: 영업사원이 하루 영업을 기록하고, 그게 미팅이 되고, 계약이 되고, 돈이 들어오는 전 과정이
> **앱 안에서 자동으로 연결**된다는 걸 보여주는 게 핵심입니다. "한 번 입력하면 끝까지 따라온다"가 메시지.

### 🎬 Step 1. 오늘 영업 기록하기 (컨택관리 📞)

**누르는 것**: 하단 탭 `📞 컨택관리`

**입력**:
1. 날짜를 시연용 날짜(예: `6/12`)로 선택
2. 채널 탭 `매입DB`(파란색) 선택
3. 4개 지표 입력:
   - 생산 `3`
   - 유입 `5`
   - 컨택진행 `2`
   - 미팅예약 `1`
4. 하단 `💾 저장하기` 클릭 → ✅ 저장 완료

**말할 멘트 예시**:
> "영업 끝나고 폰으로 숫자 4개만 찍으면 됩니다. 오늘 매입DB로 3건 생산해서, 5건 유입됐고, 2건 컨택 진행, 그중 1건 미팅 잡았다 — 이게 끝이에요. 더 적을 것도 없습니다."

---

### 🎬 Step 2. 미팅 잡기 (같은 화면 — 미팅 슬롯 추가)

**누르는 것**: 컨택관리 화면 아래쪽 미팅 슬롯 영역 → `미팅 추가`

**입력**:
- 미팅날짜: `6/13`
- 미팅시간: `14:00`
- 업체명: `(주)한국마케팅`
- 장소: `강남구 역삼동`
- 예약비고: (비워도 됨)
- `✓ 등록` 클릭

**말할 멘트 예시**:
> "방금 잡은 미팅 1건을 바로 등록합니다. 업체명, 시간, 장소만 넣으면 돼요. 이게 곧바로 일정·계약 탭이랑 캘린더에 자동으로 떠요."

---

### 🎬 Step 3. 미팅 진행하고 계약 성사 (일정·계약 📋)

**누르는 것**: 하단 탭 `📋 일정·계약` → `6/13` (주)한국마케팅 카드 펼치기

**입력**:
1. 카드 안의 `💵 계약` 버튼 클릭
2. 수임비: `5000000` (입력하면 `5,000,000` 으로 자동 콤마)
3. 계약 조건·특이사항: `6개월 분할, 부가세 별도`
4. `💵 계약 확정` 클릭 → ✅ 계약 저장 + **수납 탭에 자동으로 행 생성**

**말할 멘트 예시**:
> "미팅 결과를 카드에서 바로 기록합니다. 계약됐으면 '계약' 누르고 수임비만 넣으면 끝. 여기서 중요한 건 — 계약을 확정하는 순간, **수납 관리 탭에 이 계약이 알아서 생겨요.** 따로 또 적을 필요가 없습니다."

> 💡 (선택) 여기서 `🟠 완료`, `🔄 변경`, `✕ 취소` 버튼도 있다는 걸 1초만 보여주세요 → "계약이 안 돼도, 미팅이 미뤄져도 다 한 번에 기록됩니다."

---

### 🎬 Step 4. 돈 들어온 거 기록 (실무/수납 💰)

**누르는 것**: 하단 탭 `💰 실무/수납` → 방금 생긴 `(주)한국마케팅` 계약 카드 펼치기

**입력**:
1. 서류 체크박스 2~3개 클릭(예: `공동인증서`, `신분증`) — "서류 챙긴 것도 체크로 관리돼요"
2. 수납1 슬롯:
   - 진행기관: `신한은행`
   - 진행률: `100%`
   - 승인금액: `5,000,000`
   - 수납액: `5,000,000`
   - 수납일: `6/20`
3. `💾 저장` 클릭

**말할 멘트 예시**:
> "계약했으면 끝이 아니죠. 서류 챙기고, 돈 들어오는 것까지 여기서 관리합니다. 분할로 들어오면 1차·2차·3차로 나눠서 기록할 수도 있어요. 이제 이 계약은 '수납 완료' 상태가 됩니다."

---

### 🎬 Step 5. 한눈에 결과 보기 (대시보드 📊)

**누르는 것**: `📊 대시보드`(상단 또는 대시보드 화면)

**보여줄 것** (입력 없음, 읽기 전용):
- **영업이익 카드**: 매출/비용/영업이익이 방금 입력으로 바뀐 것
- **퍼널 차트**: 생산 → 유입 → 컨택진행 → 미팅예약 → 미팅완료 → 계약, 6단계가 채널 색깔별로
- **주간 추이**: 이번 주 계약 1건 올라간 것

**말할 멘트 예시**:
> "그리고 제가 방금 찍은 숫자들이 — 따로 엑셀 정리 안 해도 — 여기 대시보드에 실시간으로 다 그려져요. 내 영업이 어디서 새는지, 컨택은 많은데 미팅이 안 잡히는지, 미팅은 가는데 계약이 안 되는지, 이 퍼널 하나로 보입니다. **이게 '경영일지'라고 부르는 이유예요.** 기록이 아니라 경영이 되는 거죠."

---

## 시나리오 B (보조, 시간 남으면) — 계약이 안 된 미팅도 기록

> **의미**: "잘된 것만 기록하는 앱"이 아니라는 점. 실패도 자산이 된다는 메시지.

**누르는 것**: 일정·계약 📋 → 다른 미팅 카드 펼치기 → `🟠 완료` 클릭

**입력**:
- 빠른 선택 버튼에서 `예산 부족` 또는 `타사 비교` 선택
- `🟠 완료 처리` 클릭

**말할 멘트 예시**:
> "미팅 갔는데 계약이 안 됐어요. 그럼 '완료'로 사유만 남깁니다. 나중에 '내가 어떤 이유로 자꾸 놓치는지' 데이터로 보이면, 그게 다음 영업의 무기가 돼요."

---

## 시나리오 C (보조) — DB 원가까지 넣으면 '진짜 손익'이 보인다

> **의미**: 매출만이 아니라 비용(DB 구입비, 광고비)까지 넣어 **순수익**을 본다는 점. 동행멤버(실무자) 버전 예고와 연결됨.

**누르는 것**: 하단 탭 `📦 DB관리` → `매입DB` 탭

**입력**:
- 구매일 `6/12`, 업체명 `OO데이터`, 개당단가 `5000`, 주문개수 `10` → 주문금액 자동 `50,000`
- 저장

**말할 멘트 예시**:
> "매출만 보면 반쪽이죠. DB를 얼마에 사서, 거기서 계약이 몇 개 나왔는지 — 채널별 '수익률'까지 봐야 진짜 경영입니다. 동행멤버 버전에서는 이 실무 관리가 훨씬 강해질 거예요."

## ⚠️ 시연 중 돌발상황 대비 (백업 플랜)

| 상황 | 대처 |
|---|---|
| 저장이 안 되거나 느림 | "실시간으로 구글시트에 쓰는 중이라 가끔 1~2초 걸려요" 하고 자연스럽게 넘기기 |
| 로그인이 풀림 | 미리 로그인해 두면 예방됨. 풀리면 시나리오 C(설명 위주)로 시간 벌기 |
| 시간이 부족 | **Step 1 → Step 3 → Step 5만** 하면 핵심 메시지는 다 전달됨 (미팅추가·수납 생략) |
| 데이터가 이미 차 있음 | 빈 날짜를 골라 그 날짜로 시연 |
| 화면이 작아 안 보임 | 입력은 말로 설명하고, **대시보드(Step 5)만 크게** 보여주기 |

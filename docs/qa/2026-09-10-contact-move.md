범위: 애플리케이션 코드와 로컬 검증. 운영 DB/Sheets 변경·배포·외부 게시 없음.

## 동작 계약
- 시간만 틀리면 저장 확인창의 X로 닫아 입력 카드 수정. 입력 보존, 쓰기 없음.
- 같은 예정일시: 신규끼리 및 실제 예정 주의 저장된 카드와 대조, 중복이면 저장 차단.
- 이동은 선택 → 목적지 → 양쪽 수치 미리보기 → 명시적 저장. X/외부 클릭 시 이동 선택 취소 확인.
- 전체 날짜 이동은 선택하지 않은 미팅별 유입·컨택 최소 1씩을 보존. 생산은 이동하지 않음.
- 최종 저장 시 선택 채널의 남은 신규 카드도 원래 날짜에 저장. 따라서 원래 날짜로 돌아와도 카드가 사라지지 않음.
- 이동 결과는 저장 후 서버에서 재조회한 H(실제 카드 수)를 반환하고, 날짜/주차 캐시 갱신 완료 후 결과창을 표시.
- 이미 저장된 기록을 되감는 일반 Undo는 추가하지 않음. 요청의 대안인 **최종 저장 전 무변경·취소**를 적용.
- 저장 도중 실패 시 일부 반영 가능성을 명시하고 동일 스냅샷으로 재시도. 확인된 append 성공분은 재전송하지 않음. 다중 요청 전체를 원자적 DB 트랜잭션으로 바꾸지는 않음.

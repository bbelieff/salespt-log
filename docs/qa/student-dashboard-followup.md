## 운영에서 확인한 변경 전 문제

- 지정받은 관리자 계정으로 읽기 전용 확인. 원본 학생 이름·금액·화면 캡처는 이 문서에 저장하지 않는다.
- 넓은 화면: 헤더 bottom 47.25px, 페이지 배너 bottom 87.75px, 진행 배너 top 104px. **16.25px 틈** 재현.
- 우상단 대시보드 링크가 `/trainer`임을 DOM에서 확인.
- 원인: PC 루트 글꼴 13.5px에 따라 rem 헤더는 축소되는데 진행 영역 offset만 104px로 고정됨.

## 로컬 합성 브라우저 검증

`node tests/browser/student-dashboard-server.mjs`는 실제 DashboardPage/TopHeader/RoleViewSwitch/카드/주간목표와 Tailwind CSS, Next 빌드 Noto Sans KR 폰트를 사용한다. API만 가상 데이터이며 인증·운영 쓰기를 하지 않는다. 브라우저 조작은 Codex CUA로 수행했다.

| 화면 폭 | 헤더 높이 | 페이지 배너 bottom = 진행 top | 가로 넘침 | 헤더 액션 한 줄 |
|---|---:|---:|---|---|
| 320 / 360 / 390 / 768px | 56px | 104px | 없음 | 통과 |
| 1024 / 1920px | 47.25px | 87.75px | 없음 | 통과 |

- 긴 가상 수강생 이름과 수강생/트레이너 버튼을 모두 표시한 상태에서 측정. 모바일 버튼 높이 44px, PC는 전역 rem 축소 적용.
- 360px에서 scrollY 700: 진행 top 104px 유지, 재무 영역 top -491px로 본문과 함께 스크롤.
- 1920px에서 scrollY 490: 헤더/배너/진행 top 0 / 47.25 / 87.75px, 재무 top -313.5px. 고정 영역 간 틈 없음.
- 모바일 스크린샷 육안 확인: 한 줄 헤더, 진행 박스 우측 D-day, 날짜·진행 배너 고정 정상.
- 재무 영역 computed position `static`; 매출·비용·영업이익이 한 section에 포함. 대시보드 링크 `/dashboard` 확인.
- 현재 11주차 → 이전 10주차 → 다음 11주차, 이전 → 이번 주 복귀 통과. 현재 주에서 미래 이동 비활성.
- 선택 날짜 변경 시 10주 탐색 상태에서 새 기준 12주로 초기화. 수강생 변경 시에도 12주로 초기화하고 새 가상 실적 99 표시.
- 조회 503 시 이전 주차 내용을 숨기고 오류 표시. [다시 시도]로 선택한 11주 복구.
- 상세 이동 URL에 선택 date/student/returnTo 유지 확인.
- compact 요약은 기존 상위 업무 날짜 선택을 유지하며 새로운 탐색 행을 추가하지 않는다.

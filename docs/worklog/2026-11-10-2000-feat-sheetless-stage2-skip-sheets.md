# 2026-11-10 feat: 시트 없는 수강생 고유 번호 2단계

- 방법: 실제 DB 클라이언트를 메모리 DB(PGlite)로 돌리는 샌드박스에서 케이스 B 수강생으로 주요 화면 함수
  24단계를 실행 → 관문이 막은 호출의 출처(파일:줄)를 수집 → 출처마다 고침 → 0 이 될 때까지 반복.
- 첫 측정: 화면 오류 7곳(대시보드·일지·DB관리 추가·일정·계약·내보내기 등) + 뒤에서 조용히 막힌 시트 호출 20여 건.
- 고친 것: 시트 수렴 큐 7종 건너뛰기(+ pending 표식 금지) · 수강 날짜/헤더 프로필은 DB 에서 · 시트 보충
  읽기(union·존재확인)는 빈 결과 · DB관리·계약 행 번호를 DB 가 잠금 안에서 정함 · 직접생산 겹침 검사·
  생산개수는 DB · 업체정보 개명은 DB 에서 내용째 이동 · 내보내기는 DB 정본 · 상단 「시트 열기」 링크 숨김 ·
  관문 막힘 횟수 계측(`sheetless_sheet_blocked`).

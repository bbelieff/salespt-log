# 폴드 커버 화면처럼 좁은 폰에서 잘림 없애기

## Intent (왜)
- belie 2026-11-07: 「갤럭시 폴드 커버 디스플레이로 볼 때 전체적으로 잘림이 많다 — 실무/수납도, 미팅예약도. 설정한 최소 폭보다 좁아져도 잘림·기타 문제 없게」.
- 설계 최소 폭은 360px(`xs`). 폴드 커버는 약 344px(Z Fold 3~5), 옛 폴드는 280px, 시스템 글자 크게면 더 좁아진다.

## Acceptance Criteria (수용 기준)
- [x] 360px 미만 화면은 360px 화면을 비율대로 줄여 보여 준다(rem·픽셀 글자 토큰 함께). 360px 이상·PC 무변경
- [x] 280·300·344·360px 에서 컨택관리(미팅예약 펼침 포함)·일정·계약·실무/수납(업체·진행 펼침 포함)·대시보드·DB관리시트·DB생산 가로 스크롤 0, 화면 밖으로 밀린 칸 0
- [x] 360px 에서도 빠듯하던 곳 손봄: 날짜 칸 「TODAY」 잘림 → 「오늘」, 컨택관리 「유입대기」 세로 쪼개짐, 도움말 1줄 잘림 → 2줄, 일정 미팅 줄 업체명 잘림(장소는 아랫줄로), 실무/수납 진행 요약(기관·진행률) 잘림, 진행 입력칸 기관명·금액·수납일 잘림(430px 미만 두 칸씩), 업체정보 도구 줄 넘침, 대시보드 오늘 챙길 일 표·생산성 지표 설명, 카드 빛 번짐 가로 스크롤
- [x] 구조 시험 `tests/structural/narrow-screen-scale.test.ts`

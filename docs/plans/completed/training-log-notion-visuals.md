# 트레이닝일지 — 노션 시각 효과 가져오기

belie 요청(2026-11-22): 「하이라이트 색상이랑 효과 같은거 불러올때 단조롭던데 노션에서 지원하는 시각적 효과를 다 가져와줘」.

## 전에는
배경색은 종류와 상관없이 노란 형광펜 하나, 글자색은 버림. 블록 색·콜아웃 아이콘·단 나눔·표 머리줄·코드 언어·제목 4단도 버렸다.

## 바뀐 것 (노션 API 가 주는 범위 전부)
- 글자색 9종·배경색 9종을 글자 조각마다 구분. 블록 전체에 준 색(문단·제목·목록·인용·토글·체크·콜아웃)도 반영.
- 콜아웃: 아이콘(이모지·그림)과 색. 색이 없으면 노션처럼 옅은 회색 바탕.
- 단 나눔: 카드 폭 520px 이상이면 나란히(노션 너비 비율 반영), 좁으면 위아래.
- 표 머리줄·머리칸, 코드 언어 이름표, 제목 4단, 제목 토글은 제목 크기, 완료한 체크는 취소선.
- 목록 3단까지 기호 구분(●○■ / 1·a·i), 북마크는 카드, 멘션·수식 조각은 옅게, 블록 수식은 코드 상자.

## 못 가져오는 것
- 노션 API 가 주지 않는 것: 글꼴(세리프·모노)·작은 글씨·전체 너비 같은 페이지 설정, 표 칸 배경색, 이미지 크기·정렬.
- 일부러 안 한 것: 수식을 수학 기호로 그리기(별도 라이브러리 필요 — 글자로 보여 줌), 영상·임베드 재생(링크로 보여 줌), 하위 DB.

# 빠른 보기 「오늘 챙길 일」 — 실무/수납에서 눌러도 이동 · 줄 전체 누르기

- **읽는 사람**: 개발자 · **관련**: `components/dashboard/FollowUpsLauncherView.tsx`, `app/(app)/payment/_components/usePaymentFocus.ts`

## 요청 (belie 2026-10-28)
실무/수납에서 플로팅 아이콘 → 오늘 챙길 일의 실무/수납 진행건 「열기」가 무반응. 다른 화면에선 진행건 좌표로 바로 간다. 「열기」 버튼 빼고 행을 누르면 열리게, 누르는 효과도.

## 원인
`usePaymentFocus` 가 주소(`?row=&slot=&focus=`)를 **처음 화면이 열릴 때 한 번만** 읽는다. 같은 화면 안 이동은 주소만 바뀌고 다시 열리지 않아 그대로였다.

## 수정
- 빠른 보기가 목적지가 지금 화면과 같으면 `payment-focus-request` 알림(목적지 주소)을 보내고, `usePaymentFocus` 가 받아 같은 규칙으로 다시 고른다(`useSearchParams` 는 Suspense 경계 문제로 이 레포가 피하는 방식).
- 줄 전체를 링크로(「열기」 버튼 제거), 눌림 효과(살짝 줄어들고 연보라), 오른쪽 화살표, 휴대폰 44px 이상, 움직임 줄이기 설정 존중.

## 검증
- 단위: 빠른 보기 줄 링크·알림 2개, 훅 알림 수신 1개, 기존 빠른 보기·대시보드 표 19개 통과.

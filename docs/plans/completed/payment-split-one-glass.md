# 넓힌 칸 = 한 장 유리 (시안 C)

- belie: 넓힌 칸 끝이 틀 테두리에 닿아 어색, 2뎁스 선이 많아 눈이 아프다 → 시안 3개 중 C, 「연결부까지 고려해서」.
- 1뎁스: 상세 틀 바탕 회청색 #edf1f7 한 장. 업체명 띠의 모드색 그라데이션·아래 선을 없애고 같은 바탕(스크롤 때 반투명 흐림). 틀 테두리(모드색 옅은 선)는 유지 — 목록 선택 칸 → 역라운드 연결부 → 틀 테두리가 한 줄의 「탭」이라, 선택 칸 오른쪽 끝색과 연결부 채움도 #edf1f7 로(`--payment-bridge-fill`, `--tw-gradient-to`).
- 2뎁스: 넓힌 칸만 밝은 판(#fbfcfe, 윗변 빛줄·흰 테두리·짧은 그림자), 틀 끝에 닿지 않게 음수 여백 제거. 2뎁스 카드 테두리 제거 — 좁힌 칸은 연한 타일(#f8fafc), 넓힌 판 안은 상자 없이 여백. 입력 칸 선·진행건 색 선·노랑 카드는 유지. 두 칸 사이·목록과 틀 사이 세로선은 평소 숨김, 마우스 올리면 보임.
- 바탕이 단색이라 뒤 흐림은 쓰지 않는다. 스티키 제목은 판·타일과 같은 색으로 덮는다.

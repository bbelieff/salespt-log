# DB 가져오기: 「구글시트 연동」 칸 · 연결 중 표시 · 자동 확인만 연결

## Intent (왜)
- belie 2026-11-06~07: 이미 다 가져온 시트(새 DB 0건)는 「추가」가 막혀 자동 확인을 연결할 길이 없었다.
  「자동 배치를 아래로 내리고 빈 곳에 구글시트 연동 칸」 · 「연결 대상이 보이고 옆에 자동 확인 연결 중」 · 「공간 없으면 파일 업로드 영역을 줄이고」.

## Acceptance Criteria (수용 기준)
- [x] 첫 화면: 텍스트 붙여넣기 아래 「구글시트 연동」 한 줄 칸, 「자동 배치」는 아래 줄(취소 옆). 텍스트 칸에 주소를 넣던 기존 방식도 유지
- [x] 이미 연결한 시트(시트 id·탭 같음, gid 없으면 0) 주소면 칸 옆 「자동 확인 연결 중」, 배치 뒤 체크칸 대신 같은 표시 · 다시 연결 안 함
- [x] 새 DB 0건 + 체크 켬 + 아직 연결 안 함 → 「자동 확인만 연결」(공급처·유형 있어야 누름) — DB 추가 없이 연결 후 창 닫기
- [x] 폰: 업로드 칸 높이·보조 문구 줄임, 연동 칸 16px·44px
- [x] 회귀 시험 4개(연동 칸 연결 · 연결 중 표시 · 자동 확인만 연결 · 주소 아님 안내), 합성 화면 PC·375px 확인

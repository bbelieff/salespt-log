## 목표
belie 2026-11-10 「처음 오는 수강생에게 첫 DB구매·첫 DB생성·첫 미팅예약… 처음 하는 동작은 스포트라이트로 안내」 → 기획안 → 2026-11-11 「추천대로 1차 진행해줘」.
추천안: 일곱 단계 그대로 · 시작은 제안 한 줄(누르면 시작) · 지금 수강 중인 기수에도 보이되 이미 한 단계는 자동 「끝남」.

## 수용 조건
1. `@/util/first-steps`: 일곱 단계(구매·DB 넣기·컨택·미팅 예약·결과/계약·수납·돌아보기)와 판정(실제 기록만), 기억 파싱·키(계정별), 제안 조건(본인 화면·미완료·그만 보기/끝냄 아님).
2. `Spotlight`: 한 곳만 밝힘, click/gone/next 진행, 모달이 뜨면 숨김, 나중에·Esc·다시 보지 않기, 마무리 말풍선.
3. 대시보드 `FirstStepsCard`: N / 7, 다음 단계, 해 보기(`?tour=`)/바로 가기/차트 보기, 숨기기, 다 하면 사라짐, 수강생 본인만.
4. 안내 2종: DB관리시트 `db-add`(「＋ DB 추가」 → 확인 화면 스포트라이트로 이어짐), 컨택 `meeting`(컨택진행 ＋[필요할 때만] → 미팅예약 ＋ → 새 미팅 카드 등록).

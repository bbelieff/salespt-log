# 할 일 고치기 창 — 저장 말고는 못 빠져나가던 오류 · 일정 눌러 고치기

- **읽는 사람**: 개발자 · **관련**: `app/(app)/payment/_components/TodoFormModal.tsx`, `TodoRow.tsx`, `components/DirtyGuard.tsx`

## 요청 (belie 2026-10-28)
- 오류신고(2026-10-28 20:13, 실무/수납 휴대폰): 투두 제목 눌러 고치다 「저장하고 넘어갈지」 창이 뜨면 바깥을 눌러도 안 빠지고 저장만 된다. belie 캡처 = 「할 일」 창 뒤에 「저장하지 않고 나갈까요?」가 흐리게 깔림.
- 「다음」으로 넣은 투두의 일정을 누르면 일정을 고칠 수 있게(지금은 지우고 다시 만들어야 함).

## 원인
1. 할 일 창이 열리기만 해도 「저장 안 한 변경」으로 등록(`useDirtyEntry(..., true, ...)`) → 닫을 때마다 확인창.
2. 할 일 창 `z-[400]` > 확인창 `z-[350]` → 확인창이 뒤에 깔려 보이지도 누르지도 못함.

## 수정
- 바꾼 칸이 있을 때만 확인창(열어 보고 닫으면 바로 닫힘).
- 할 일 창을 다른 확인창들과 같은 `z-[300]` 으로 — 확인창이 위에 뜬다.
- 할 일 줄의 일정(날짜·시각)도 눌러서 같은 고치기 창을 연다(점선 밑줄·눌림 색).

## 검증
- 단위: 바꾼 것 없음→dirty false / 바꿈→true / 겹침 순서 < 350, 일정 버튼 → 고치기, 기존 할 일 시험 통과.

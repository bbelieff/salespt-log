# 업체정보 칸 배치 정리

1. 공고필터: 펼침엔 아직 안 된 조건만, 3/3이면 칩을 숨긴다(맞는 공고가 있으면 「맞는 공고 N」은 그대로).
2. [기업정보] 개업일 · 사업자구분/과세유형 · 사업자등록번호를 한 줄(EditorItem `bizRow`, 3:4:3, 360px 미만 세로). 기본보기는 그대로.
3. 소유여부(기업정보·대표자 공용): 주소지 아래 [면적 | 소유여부 드롭다운(자가·임차·임차(무상)·기타)], 임차면 그 아래 [보증금 | 월세]. 단위는 칸 안에 흐리게.
   - 보증금·월세는 **천원으로 보이고 적지만 저장은 원** — 기존 학생 데이터(원)를 바꾸지 않고, TXT·서류 자동입력(임대차 파서, 원)과 그대로 맞는다. 되돌려도 데이터 손실 없음.
   - 목록 밖 옛 글(예: "배우자명의 무상사용")은 고를 수 없는 「지금 값」으로 보이고, 다른 값을 고르면 기타메모로 옮긴다.
4. 기타메모: 「전체」 보기에서 적었어도 늘 맨 아래(추가한 칸·「필드 추가」 바로 위).

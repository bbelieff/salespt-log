# 오늘 활동 — 날짜 넘기기 (2026-11-08)

## 목표 (belie 2026-11-08)
「일별 기록 전체 →」 문구 고민에서 나온 안 — 화면을 떠나지 않고 어제·그제 숫자를 바로 넘겨 본다.

## 수용 조건
1. 펼친 머리에 ‹ 날짜 › — 하루 전/하루 뒤. 오늘보다 뒤로는 못 간다(› 비활성).
2. 지난 날이면 제목 「지난 활동」, 날짜 초록, 「오늘로」 알약.
3. 흐름 4칸·채널 표·유입대기·현수막 게시가 그날 기준. 현수막 게시 저장도 그날(`/api/daily/그날`).
4. 읽는 동안 이전 숫자를 흐리게(50%) 유지, 그날을 못 읽으면 안쪽 한 줄 안내(패널 자체는 유지).
5. 닫힘 띠·카드는 늘 오늘. 닫으면 오늘로 돌아온다.
6. 아래 링크 문구 「일별 기록에서 고치기 →」(기록 옮기기·자세한 고치기는 일별 기록 탭).

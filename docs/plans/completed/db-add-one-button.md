# DB 추가 하나로 (2026-11-07)

## 목표 (belie 2026-11-07)
- 「DB 등록만 잘 되면 숫자는 저절로 오른다」 — 등록 입구를 하나로, 클릭·방황 최소.
- 현수막처럼 통화가 먼저 된 DB 는 녹음(또는 받아쓴 글)을 올리고 채널만 고르면 업체정보·상담메모·미팅까지 채운다.
- 승인된 목업: J3(녹음 고른 뒤 — 파일·「오늘 14:12 · 3분 12초 · 통화 녹음」·채널 4개·정리 시작), K1·K2(폰도 가운데 팝업), 녹음한 날 = 유입일.

## 수용 조건
1. 목록 위 버튼은 「＋ DB 추가」 하나. 창에서 엑셀·붙여넣기·구글시트(기존 그대로)·통화 녹음·통화 글·직접 입력을 고른다.
2. 녹음·PDF·통화로 보이는 .txt(이름에 번호·통화·녹음) → 채널 단계. 그 밖의 .txt·엑셀은 기존 가져오기.
3. 이름 속 번호가 목록에 있으면 채널을 묻지 않고 그 줄 통화로 올린다(중복 DB 방지).
4. 새 DB 는 유입일 = 녹음한 날(이름의 날짜·시각 → 없으면 파일 저장 시각, 미래면 오늘), 공급처 = 채널, 유입 반영 켬. 통화 시각은 서버 규칙(지난 7일)에 맞을 때만 보낸다.
5. 처음 보내는 폰은 외부 AI 고지(D6)를 먼저 보여 준다.
6. 정리 확인 화면: 업체명·대표가 빈 줄이면 맨 위 「새 DB」 칸(채널·유입일·전화, AI가 들은 업체명·대표 고치기).
7. 통화 기능이 꺼진 사람(GET /api/calls 404)은 녹음을 받지 않는다 — 기존 가져오기 + 직접 입력만.
8. 직접 입력은 업체명·대표자 중 하나만 있으면 저장.
9. DB 구조·운영 DB 변경 없음(줄을 먼저 만들고 기존 통화 흐름에 태운다).

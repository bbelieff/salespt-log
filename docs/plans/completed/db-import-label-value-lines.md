# DB 붙여넣기 — 항목 줄·값 줄 형식 (2026-11-09)

## 목표 (belie 2026-11-09 「지금방식으로도 볼 수 있게 해줘」)
새 DB 업체 글은 `이름` 다음 줄에 값, `전화번호` 다음 줄에 값 … 처럼 온다. 지금은 줄마다 고객 한 명으로 읽어 19건으로 쪼개졌다.

## 수용 조건
1. 아는 항목 이름만 있는 줄이 3개 이상(전화번호 포함)이고 `항목: 값` 줄·탭·세미콜론이 없을 때만 `항목: 값` 으로 합쳐 기존 「항목별 텍스트」로 읽는다.
2. 모르는 항목(사업자 종류 등)은 원문 메모로. 값 뒤 긴 줄(첫 인콜 멘트)은 앞 값에 이어 붙인다.
3. 같은 항목이 다시 나오면 다음 고객. 앞 인사말은 고객이 아니다.
4. `상호명`·`싱호명`(업체 표기) → 사업자명, `광고 내용` → 상담메모.
5. 콜론 항목·표·줄별 텍스트 입력은 바뀌지 않는다.

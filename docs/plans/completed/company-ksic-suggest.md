# 표준산업분류 추천 이식

## MSC 방식(조사 2026-11-04, `원페이지경영진단 자동화시스템/리드디벨롭/tools/doc-parsers.js:816-871`)
- 분류표: 통계청 11차(2024-07 시행) 세세분류 1,205항목 + 해설서 「예시」 낱말을 JSON 으로 앱에 내장. 외부 호출·AI 없음.
- 비결: ① 종목 낱말이 이름·예시 낱말과 **통째로** 같으면 4점, 글자 일부면 2.5(「학원」이 「대학원」에 붙지 않게) ② 흔한 낱말(판매·서비스·제조 …)은 무게 0.3 ③ 붙여 쓴 말은 **두 글자 조각 겹침**(자동차부품) ④ **업태는 점수를 더하지 않고 대분류 배수만**(맞으면 ×1.6 · 아니면 ×0.6, 도매/소매 46·47 선호) ⑤ 생활 낱말 10개 별칭(카페·꽃집·미용실·인테리어 …).
- 한계: 정답 사례 10개만 시험, 정확도 측정 없음. 분류표는 통계청 원본을 공개 R 패키지(urbanjj/KSIC) 경유로 받은 것 — 통계청 고시와 대조 기록 없음.

# 오늘 활동 패널 (2026-11-07)

## 목표 (belie 2026-11-07)
- 「오늘 마감 말고 오늘 활동」, 반 페이지, 관리시트를 떠나지 않고 살짝 나와 있다가 누르면 덮어 들어오는 방식. 표시한 높이까지 나와 있어도 된다(목업 0-v2).
- 「DB 등록만 잘 되면 숫자는 저절로」 → 손으로 더하는 건 현수막 게시(사람이 없는 활동)만. 문의·소개·콜드콜은 「＋ DB 추가」로.

## 수용 조건
1. 닫힘: 폰 아래 띠 / PC 오른쪽 아래 카드 — 생산·유입·컨택·미팅 오늘 합계, 「＋ DB 추가」, 「＋ 현수막 게시」.
2. 펼침: 폰 아래 반, PC 오른쪽 반. 흐름 4칸 · 채널별 표 · 현수막 게시 −/＋(재고) · 일별 기록 링크 · 「＋ DB 추가」.
3. 숫자는 일별 기록 API 그대로. 현수막 게시는 현수막 줄만 저장(다른 칸·DB 목록 기준값 그대로).
4. 「＋ DB 추가」는 「DB 추가」 창(PR #1359)을 연다.
5. 일별 기록 탭은 그대로(지난 날짜·기록 옮기기).

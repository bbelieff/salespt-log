# 미팅예약 펀넬 = 04 상태기반 (A안)

## 배경 (선행 진단 meeting-done-status-filter)
- 미팅완료(R5:U5)=ΣL=상태(완료·계약) 정확. 미팅예약(R4:U4)=ΣH(웹 일일 지표)라 추가미팅·미래 예약 누락 → 예약18=완료18 → 실행률 100% 착시(오승진/문보혜).
- 대시보드 앱은 `01!R1:U6`(채널 stacking)를 읽어 미팅예약/완료/실행률 표시.

## 확정 정의 (A)
- **미팅예약** (펀넬 + 실행률 분모) = 04 상태 ∈ {예약, 완료, 계약} (변경/취소 제외, 미래 예약 포함).
- **미팅완료** = 04 상태 ∈ {완료, 계약} (현행 유지).
- 결과: 예약 ≥ 완료 항상. 오승진: 예약 20(계약10+완료8+예약2) > 완료 18 → 실행률 90%.

## 변경 (시트 수식만 — service/repo 무변경)
- `setup-formulas.ts:meetingFunnelFormulas()` 신규 → 설치 스텝 추가:
  - `R4:U4`(채널별 미팅예약) = `COUNTIFS(04.F,채널,04.J,"예약")+("완료")+("계약")`.
  - `R5:U5`(채널별 미팅완료) = `COUNTIFS(...,"완료")+("계약")`. (기존 ΣL 채널무관 왜곡도 교정.)
  - `F4`=SUM(R4:U4), `F5`=SUM(R5:U5) → 펀넬 합 + 실행률(I5=F5/F4) 자동 정합.
  - 채널은 04.F. 콜·지·기·소는 separator 변종 대응 와일드카드 `"콜*소"`(#319 동일).
  - §2.5 isSafeToOverwrite 가드(raw 보존). 04 는 본인 미팅만 담겨 전체 카운트=코스 총계.
- 대시보드 service/repo 는 R1:U6 시트값을 읽으므로 **코드 변경 불필요**(사용자 #1 일치).
- 컨택탭 H(일일 미팅예약 지표) 는 그대로 — 펀넬/실행률만 04 기준. (H↔펀넬 차이는 정의 차이로 문서화; H 파생 통합은 fix-meeting-reservation-cascade 후속.)

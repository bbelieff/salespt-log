# 간편인증 — 같은 요청 두 번 막기 (2026-11-10)

## 목표 (belie 2026-11-10, UI 점검 보고서 1-5 「진행」)
처리 중에도 「승인 확인·다시·취소」가 눌려 같은 요청이 두 번 갈 수 있었다. 진행 중 취소는 확인 없이 바로, 오류 안내는 3.5초 뒤 사라졌다.

## 수용 조건
1. 처리 중(`busy`)엔 목록의 승인 확인·다시·취소·기록 삭제가 잠긴다.
2. 화면이 잠기기 전 빠른 연타도 막는다(요청이 끝나기 전 두 번째 요청은 보내지 않음).
3. 승인 대기 중 「취소」는 「보낸 인증을 취소할까요?」를 묻는다.
4. 실패 안내는 빨간 바탕으로 10초, ✕ 로 닫을 수 있다. 성공 안내는 3.5초 그대로.

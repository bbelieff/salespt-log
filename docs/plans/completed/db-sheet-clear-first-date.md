# DB정보 최초상담일 지우기 · 부재 시간 막대 12시 눈금

- 요청(2026-11-01 belie): 최초상담일을 한 번 넣으면 지울 수 없음(달력 「재설정」 무반응) → 지울 수 있게. 부재 시간 막대에 12시 눈금, 「부재 걸었던 시간」 문구 삭제.
- 원인: 아이폰 달력 「재설정」은 입력의 원래 값(React 가 현재 날짜로 맞춰 둠)으로 되돌려 변화가 없다. PC 등에서 비워도 다음 읽기 때 컨택 기록으로 다시 채워졌다(`backfillDbSheetDates`).
- 변경: 최초상담일 제목 줄 「지우기」 버튼(날짜 있을 때만). 서버가 직접 비움을 `firstCleared` 로 기억해 읽기 보정이 다시 채우지 않음. 막대 아래 눈금 08·12·21시(14칸 격자 정렬).
- 수용: 지우기 → 빈 값 저장·새로고침 뒤에도 빈 값 / 날짜 다시 넣으면 정상 / 눈금 12시가 다섯째 칸 아래.
- 되돌리기: squash revert. 데이터 변경 없음(새 필드는 비운 업체에만 생김).
- 추가(같은 날 belie): DB정보 머리줄 — 닫기를 업체명 줄 오른쪽에 나란히, 유입 반영은 닫기 왼쪽에 세로선으로 구분.

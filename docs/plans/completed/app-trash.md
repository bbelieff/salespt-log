# 앱 휴지통 — 지운 할 일·미팅·DB관리시트를 한 곳에서 되살리기

- **읽는 사람**: 개발자 · **관련**: `lib/service/trash.ts`, `app/api/trash/route.ts`, `app/(app)/trash/*`, `lib/repo/db/todo-trash.ts`

## 요청 (belie 2026-10-28)
「삭제된 것 모아 놓은 휴지통」 → 질문 답: 「앱 전체 한 곳, 깔끔한 테이블, 행 선택해서 되살리기만」.

## 근거 (실측)
- 할 일·계약·미팅 삭제는 DB 행에 `{_cleared:true}` **병합** — 내용이 그대로 남아 되살릴 수 있다(`lib/repo/db/client.ts` UPSERT `payload || excluded.payload`).
- 미팅은 이미 보관함·복원(`meeting-archive`, 계약 연결 미팅은 복원 차단)이 있고, DB관리시트는 자체 휴지통(`trash-restore`)이 있다.

## 범위
- 할 일(신규 목록·되살리기: 지움 표시만 걷고 시트·구글 캘린더 재동기화) + 미팅(기존) + DB관리시트(기존, 한 건씩 — 같은 업체 있으면 그 건만 막힘).
- **계약은 제외**: 지울 때 연결 미팅을 「계약 → 예약」으로 되돌리므로 계약만 되살리면 서로 어긋난다. 별도 설계 필요.
- 영구 삭제 없음. 되살린 뒤 모든 화면 데이터를 새로 읽는다.

## 검증
- PGlite: 지운 할 일만·최근 순·내용째, 빈 옛 행·다른 시트 제외.
- 서비스: 세 곳 합치기·정렬·막힘 이유, 하나 실패해도 나머지 진행. 할 일 되살리기 병합 인자·거부 조건.
- 합성 화면 375px: 표·행 누르기 선택·막힌 줄 선택 불가·결과 안내.

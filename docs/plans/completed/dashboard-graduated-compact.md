# 대시보드·오늘 활동 다듬기 (2026-11-08, belie 요청 4건 「바로 운영반영」)

## 수용 조건
1. 수료(`graduated`)면 진행바·시작·진행률·종강총회 줄 없음 — 날짜·「🎓 수료 후 N주」·수료 배지 한 줄.
2. 「오늘 챙길 일」 펼친 표(폰·좁은 창): 줄 높이 ↓(할 일·열기 34px, 누르는 범위 44px 유지), 할 일 아래 `MM.DD · 기관/상태` 한 줄.
3. 오늘 활동 PC 카드 288px, 떠 있는 버튼 왼쪽(right 96px). 폰·태블릿은 떠 있는 버튼을 아래 띠 위로.
4. 현수막 게시: 장수 칸 직접 입력(0~999, Enter·벗어나면 저장, Esc 취소) + −1·＋1·＋5·＋10. 닫힘의 「＋ 현수막 게시」는 패널을 열고 장수 칸에 커서. 저장은 현수막 줄만.
5. 폰: 오늘 활동 띠를 위로 쓸어 올리면 반쪽 화면이 아래에서 미끄러져 올라오고, 펼친 머리를 아래로 쓸면 닫힘(PC 는 오른쪽에서). 움직임 줄이기 설정이면 바로.
6. 펼친 채널별 표에서 네 칸이 모두 0인 채널은 뺀다. 다 0이면 「아직 오늘 기록이 없어요」.
7. 현수막을 산 적이 없으면(`bannerOrderQty` 0, 오늘 게시가 있어도) 현수막 게시 칸·「＋ 현수막 게시」 버튼을 뺀다. 재고보다 많이 늘리면 저장하지 않고 남은 재고를 알린다(줄이기는 언제나 됨). `bannerStockBase` 는 오늘 게시를 더한 값이라 구매 여부 판단에 쓰지 않는다.
8. 현수막 게시 칸 제목 옆과 「＋ 현수막 게시」 칩에 재고를 보여 준다(0이면 빨강).
9. 펼친 「오늘 활동」에 매입DB 유입대기 N개(일별 기록과 같은 셈 inflowWaitBase − 오늘 유입)를 보여 준다. 매입DB 생산도 대기도 없으면 뺀다.

# 트레이닝일지 — 수강생마다 자기 일지만 보기 (A안 구현)

## Intent
belie(2026-10-30): 업무도구에 트레이닝일지 바로가기. 노션 기수 페이지(예: 「[11기] 세일즈PT 수강생 트레이닝 피드백」)를 통째로 열면 안 되고, **각 수강생이 자기 일지만** 봐야 한다.

## 현재 노션 구조 (2026-10-30 실측)
- 기수마다 페이지 1개. 그 안에 지역별 인라인 DB: `[서울11기] 트레이닝 일지`, `[부산11기] 트레이닝 일지`.
- DB 속성: `제목`(예 「최석민 대표님 3주차 트레이닝 일지」) · `상태`(select, **수강생 이름** — 보드가 이 값으로 열을 나눔).
- 페이지 본문 = 주차 복기·과제·경영일지 체크·케이스 피드백·**트레이너 피드백**·목표.
- 기수 페이지에는 다른 수강생 이름·클라우드 폴더 링크·트레이너 시간표가 같이 있다 → 링크 공유 방식은 남의 정보가 보인다.

## 선택지
| 안 | 방식 | 남의 일지 차단 | belie 수작업 | 판단 |
|---|---|---|---|---|
| **A (추천)** | 서버가 노션 API로 읽어 **앱 안에 내 일지만** 보여 줌 | 확실(서버에서 이름으로 거름) | 노션 연결 1회 | 채택 후보 |
| B | 일지 페이지마다 「웹에 게시」 후 링크만 앱에 | 링크 아는 사람은 누구나 열림 | 매주 페이지마다 게시 | 기각 |
| C | 수강생별 DB를 따로 만들어 노션 게스트로 초대 | 됨 | 기수마다 DB·초대, 수강생 노션 가입 필요 | 기각 |

## A안 상세
1. **들어가는 길**: PC 업무도구 「트레이닝일지」 → 앱 안 `/training-log` (새 탭 아님, ↗ 없음).
2. **목록**: 내 일지 주차 카드(최신 위). 누르면 같은 화면에서 본문(제목·목록·토글·표·굵게/색·링크·이미지) 읽기 전용 표시. 「노션에서 열기」 링크는 **두지 않는다**(기수 페이지 권한이 없거나, 있으면 남의 것이 보이므로).
3. **내 것 찾기**: 로그인 세션의 `기수`+`이름`(registry)만 쓴다. 클라이언트가 이름을 보내지 않는다. 기수 → 노션 DB는 노션 검색으로 제목 `[*N기] 트레이닝 일지` 를 자동으로 찾고(새 기수마다 설정 0), `상태 = 내 이름` 인 페이지만 가져온다. 동명이인은 기수 DB가 달라 섞이지 않음. 이름이 없으면 「아직 일지가 없어요」.
4. **트레이너·관리자**: 1차는 숨김(수강생 전용). 필요하면 2차에 담당 수강생 선택.
5. **서버**: `lib/repo/notion-client.ts`(googleapis처럼 repo에 격리) → `lib/service/training-log.ts` → `GET /api/training-log`, `GET /api/training-log/[pageId]`(그 페이지의 `상태`가 내 이름인지 **다시 확인** 후 본문 반환). 5분 캐시, 노션 초당 3회 제한 준수. 이미지 주소는 1시간 만료라 매번 새로 받음.
6. **쓰기 없음.** 노션 원본은 읽기만.

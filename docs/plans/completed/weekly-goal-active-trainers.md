# 주간목표 담당T = 수강생관리 담당

- 증상(2026-11-06 belie): 수강생관리에서 담당이 한 명인데 주간목표 회의표 담당T에는 두 명(이전 트레이너 포함)이 나온다.
- 원인: 두 화면이 같은 저장 칸(레지스트리 담당 칸)을 읽지만, 수강생관리는 2026-11-03부터 퇴출·관리부서 트레이너를 표시에서 빼고(저장 칸 정리는 그 수강생 담당을 바꿀 때만), 주간목표는 저장 칸을 그대로 이름으로 바꿨다. 그래서 퇴출된 트레이너 잔재가 주간목표에만 보였다.
- 변경: 활성 트레이너 판정을 `trainer-pool.ts` 순수 함수로 두고 주간목표가 같은 규칙으로 거른다. 저장 데이터는 건드리지 않는다.
- 수용 기준: 저장 칸에 퇴출 트레이너가 섞여 있어도 담당T 에 활성 트레이너만 · 풀을 모르면 거르지 않음 · 주간목표 기존 시험 통과.

# 실무/수납 헤더 깨짐 · 장기관리 묶음 · DB관리 날짜 버튼

## 목표·수용조건
1. 「맞는 공고」·「공고필터 → 채우기」를 눌러도 PC 실무/수납 머리(상세 배너·목록 탭)가 밀려 사라지지 않는다.
   원인: 작업판 바깥 틀이 `overflow:hidden` — 화면에 안 보여도 스크립트 스크롤(scrollIntoView)이 되는 상자라 판 전체가 위로 밀렸다. → `overflow:clip`(스크립트로 못 미는 상자) + 상세 배너 sticky.
2. 장기관리 업체는 목록 맨 아래 「장기관리 업체 N곳」 접힌 묶음(belie 승인안). 칩 제거, 펼침 기기 기억, 검색·선택·옮겨짐 때 자동 펼침, 묶음별 정렬, 기관 보기 동일.
3. 실무진행은 모두 접힌 채(비어 있어도). 방금 「진행 추가」한 것만 펼침.
4. DB정보 날짜: 최초상담일 「당일·익일」, 다음 연락일 「익일·1주일·1개월(뒤)」, 장기관리 「1·3·6개월 후」.
   장기관리 업체의 다음 연락일이 마지막 연락에서 4주 이상 뒤면 그날이 다가올 때 오늘 챙길 일에 다시 올라온다(넘기기 전 남은 옛 날짜로 쏟아지지 않게).
5. DB정보가 PC 한 화면에 스크롤 없이 들어온다.

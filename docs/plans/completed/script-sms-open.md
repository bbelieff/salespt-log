# feat: 대본 문자 양식 → 문자 앱 열기

## 목표
belie 2026-11-10 「①번 문자 앱 열기 버튼도 만들어줘」. 삼성 메시지는 외부 발송 API 를 공개하지 않아,
문자 발송 업체 API(건당 요금·발신번호 등록) 대신 `sms:` 주소로 폰 기본 문자 앱을 여는 길(①안)을 택했다.
보내는 번호는 수강생 본인 폰, 보내기 버튼은 본인이 누른다. 서버·DB·비용 변화 없음.

## 수용 조건
1. 대본 패널 [문자 양식] 제목 줄에 「문자 앱」 버튼(「복사」 왼쪽). 누르면 `sms:` 로 문자 양식 본문이 채워진 문자 앱이 열린다.
2. DB관리시트 「대본 보기」 창은 그 줄의 번호를 넘겨 받는 사람까지 채운다. 업체정보 「대본」 탭은 번호가 없어 받는 사람은 앱에서 고른다.
3. 주소 모양(`lib/util/sms-link.ts` `smsHref`): 번호 있으면 `sms:<숫자>?&body=`(안드로이드·iOS 공통), 없으면 iOS `sms:&body=`·그 밖 `sms:?body=`. 본문은 encodeURIComponent.
- 회귀 시험: tests/util/sms-link.test.ts.

## 범위 밖
- 문자 발송 업체 API 연동(②안), 본문의 「OOO대표님」 등 자리표시 자동 치환.

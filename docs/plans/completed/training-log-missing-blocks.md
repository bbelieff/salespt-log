# 트레이닝일지 — 본문 일부가 빠져 보이던 것 고치기

## Intent
belie(2026-11-16): 「김태진 수강생 업무도구>트레이닝일지에서 6주차·7주차 일지가 잘못 잡혀 있다. 김태진만의 문제가 아니면 원인 해결」.

## 확인한 사실(노션 읽기 전용, 2026-11-16)
- 목록·연결은 맞다: 부산12기 DB 의 김태진 1~8주차 행이 정확히 잡히고, 받은 6·7주차 링크와 같은 페이지다.
- 본문이 빠졌다: 트레이너가 6주차부터 노션 **제목 4단계(heading_4)** 블록을 쓰기 시작 — 앱이 모르는 블록이라 블록과 **그 아래 내용 전체**를 버렸다. 6주차는 「신보 한바퀴 진행 가이드 6단계」 아래 대부분, 7주차도 2곳.
- 6주차는 목록 안 목록이 6단까지 — 4단에서 읽기를 끊어 맨 안쪽 12블록도 빠졌다.
- 다른 수강생도 같다 — 11·12기 36편(집계는 worklog).

## 변경
- `heading_4` → 작은 제목(접히는 제목이면 토글).
- 일지 안 하위 페이지(child_page)는 제목을 굵게 남기고 내용을 아래에 펼친다.
- 모르는 블록 종류도 글자·자식이 있으면 문단으로 남긴다(노션이 새 블록을 더해도 조용히 빠지지 않게). 하위 DB 등 빈 블록은 계속 숨김.
- 본문 읽기 깊이 4 → 8(전체 양은 기존 600블록 상한).

## 수용 기준
- 단위 시험: heading_4·토글 제목·모르는 블록·숨길 블록.
- 배포 후 6주차 본문에 「신보 한바퀴 진행 가이드 6단계」 아래 내용이 보인다.

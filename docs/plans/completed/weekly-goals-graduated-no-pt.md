# 수료 후 주간 목표 — PT과제 · 복사 · 회의록 감춤

## 배경과 승인
- belie 2026-11-25(대시보드 접힌 카드 캡처와 함께): 「졸업후에는 PT과제 라는 내용을 없애줘. 클립보드복사랑 회의록 열기도 없애주고」.

## 결정
1. **판정**: 조회 응답에 `graduated` 를 더한다 — 오늘이 총회일(총회일이 없는 기수는 저장된 수료일) 뒤. 대시보드 진행 줄(`computeCourseBanner`)과 같은 끝 날짜. 끝 날짜를 모르면 수강 중으로 본다(잘못 감추지 않는다).
2. **대시보드 카드**: 접힌 줄 이름 「주간 목표」. 펼친 카드는 PT과제 미리보기 칸 없이 목표 링만.
3. **주간 목표 화면**: 제목 「주간 목표」, PT과제 입력·지난 PT과제·(트레이너) 지난주 PT과제 성과를 감춘다. 클립보드 복사 판 전체(복사 버튼·회의록 Notion 열기·미리보기 표)를 그리지 않는다.
4. **남기는 것**: 다섯 목표 입력, 역산 제안, 트레이너 특이사항.
5. **데이터**: 저장된 과제 글·성과 기록은 지우지 않는다. 목표만 고쳐 저장해도 기존 과제 글을 그대로 보낸다.

## 범위 밖
- 트레이너 수강생 목록 표의 「PT과제」 열(수강 중·수료생이 섞인 표).
- 사이드 메뉴 이름(이미 「주간목표」).
- 저장 API 는 수료 후 과제 글을 막지 않는다(화면만 감춤).

## 수용 기준
- 수료 후 주간 목표 화면·대시보드 카드에 「PT과제」「클립보드」「회의록」 글자가 없다.
- 수강 중 화면은 바뀌지 않는다.
- 수료 후 목표를 고쳐 저장해도 저장돼 있던 과제 글이 그대로 남는다.

# 떠오른 칸 스티키 틈·그림자 정리

- 틈: 떠오른 칸에 준 위 여백 10px 때문에 스티키 제목이 열 맨 위가 아니라 10px 아래에 붙었고, 그 틈으로 스크롤되는 내용이 비쳤다 → 떠오른 칸 안에서만 제목 `top:-10px`, 진행건 제목 `top: 1.875rem - 10px`.
- 끊긴 그림자: 옆 칸의 스티키 제목(z-index 10)이 떠오른 칸(z-index 없음)보다 위에 그려져 그림자를 덮었다(「계약정보 좌상단 테두리 깨짐」·로드맵/실무진행 제목띠) → 떠오른 칸 `position:relative; z-index:11`.
- 어색한 연결부: 그림자가 좌우로 번져 상세 칸 가장자리와 만나는 곳이 지저분했다 → 음수 spread 로 아래로만 떨어지는 그림자.
- 확인: 합성 화면 1440px 2배 캡처, 두 칸 각각 스크롤 250px 후 제목 위치·z-index 측정.

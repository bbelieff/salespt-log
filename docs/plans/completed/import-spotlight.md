# feat: DB 추가 확인 화면 스포트라이트

## 목표
belie 2026-11-10: 수강생이 ① 수집경로·공급처·유입일 칸을 못 보거나 ② 확인 필요 칸이 남아 「추가」가 안 되는 병목. 시안(캔버스 「DB 추가 확인 화면 개선안」) 「키노트하듯 음영으로」 → 「이 느낌 좋은데? 운영반영 해주고」.

## 수용 조건
1. 공통 3칸을 `fieldset.ai-common` 「① 먼저 정해 주세요 — 이번에 넣는 DB 공통」으로. 라벨 수집경로(유형)·공급처·유입일, 빈 칸 「필수」·「N건 비어 있어요」, 채우면 「채움」.
2. 추가가 막혀 있으면 한 곳만 `.ai-spot`(바깥 `--ui-scrim` 음영): 공통 3칸 → 표(노란 칸·빠진 칸, 나머지 줄 흐리게) → 표(중복 의심). 안내 「N / 3 · …」. 다 풀리면 음영 없음.
3. 발 영역 「확인할 곳으로 →」(첫 칸으로 스크롤·초점). 기존 「추가 전 확인: …」 문구·추가 버튼 잠금은 유지.
4. 노란 칸 답을 같은 열 나머지 줄에도 적용(기본 켬, 끌 수 있음). 이미 값이 있는 줄은 건너뜀.

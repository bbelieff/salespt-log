# 닫기 전 확인 — 공용 문구 (2026-11-10)

## 목표 (belie 2026-11-10, UI 점검 보고서 1-3 「일반적인 표현으로 바꿔서 진행」)
DB 추가 창은 Esc 한 번에, 통화 정리 확인은 「나중에」에, 계약 해지 창은 바깥 클릭에 적던 내용이 사라졌다. 일반 일정 안내창은 취소가 없었다. 창마다 다른 말 대신 하나의 일반적인 문구로 묻는다.

## 수용 조건
1. 공용 `confirmDiscard(dirty)` — 바꾼 게 없으면 묻지 않고 닫는다. 있으면 「작성 중인 내용이 있어요.
저장하지 않고 닫을까요?」.
2. DB 추가 창: 붙여넣은 글·시트 주소·배치 결과가 있으면 Esc·✕·취소가 묻는다(추가 완료·자동 확인 연결 뒤 닫힘은 묻지 않음).
3. 통화 정리 확인: 고친 게 있으면 닫기·「나중에」가 묻는다.
4. 계약 해지 창: 사유·반환 선택·숨김을 바꿨으면 바깥 클릭·취소가 묻는다.
5. 일반 일정 첫 안내창: 「취소」(폼으로 돌아감) + 「확인하고 추가」.

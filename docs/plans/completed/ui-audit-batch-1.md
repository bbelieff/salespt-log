# UI 점검 묶음 1 (2026-11-10)

## 목표 (belie 2026-11-10 보고서 댓글)
1. 「저장중..」으로 통일 — 「저장 중…」「저장중...」「저장중」 등 30곳.
2. 일정 화면 시간 선택도 08~21시(TimePicker15). 범위 밖 기존 값(07:30·22:00)은 컨택·일정 모두 「--」 대신 그대로 보이게(TimeSelectPair 포함).
3. 개발 용어 정리(「사용자는 눈치채지 못하게」) — registry row·5탭 UI·impersonation·Impersonating·row 삭제·수납탭 계약카드·backfill 등 → 쉬운 말. 트레이너 확인창은 이메일 대신 이름(이메일).
4. 수강생 검색: 관리자 검색이 승인 대기·유보에도 걸리고, 검색 중엔 보관 기수·유보 상자를 펼침. 트레이너 화면에 검색칸(검색 중엔 내 담당/전체와 상관없이 전체에서 찾기).
5. 「자동 확인만 연결」 실패 때 「DB는 추가했지만…」 → 「자동 확인은 연결하지 못했어요…」.
6. 입력칸 이름표 연결(htmlFor/id): 수납 진행건 6종, 컨택 미팅 카드 2종, 계정 연결 4칸.

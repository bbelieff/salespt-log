# DB관리 일괄 처리 줄 — 체크했을 때만

belie 요청(2026-11-22): 「이 줄은 DB에 체크박스를 하나라도 누르면 그때 나타나는 걸로」.

- 변경: 체크한 줄이 0이면 `BulkBar` 를 그리지 않는다. 안내 문구(「줄 앞 칸을 체크하면…」)는 없앴다.
- 예외: 처리 중이거나 결과 문구(예: 못 바꾼 줄 안내)가 남아 있으면 체크가 0이어도 줄을 유지한다 — 삭제 뒤 선택이 풀려도 결과를 읽을 수 있게.
- 확인: `tests/components/db-sheet-grid-selection.test.ts`(0줄=없음, 문구만 있음=유지, 2줄=버튼 동작). 실제 화면은 배포 뒤 확인.

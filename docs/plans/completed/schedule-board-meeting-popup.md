# 주간 보드 — 미팅 창·트레이닝 목표 판을 시안 구성으로

- 요청: belie 2026-11-12 「라이브버전은 지금 목업대로 안되고 있는데 … 구버전의 컴포넌트를 쓰고 있는데?」 + 「트레이닝목표도 좀 다르게 나오고 있고」.
- 원인: 보드 미팅 창이 시안의 창이 아니라 목록 화면 미팅 카드(MeetingResultCard)를 통째로 넣었고, 트레이닝 목표 판은 시안의 막대 목록 대신 요약 배지(WeeklyGoalSummary compact)를 썼다.
- 목표: 두 곳을 시안 v44 구성·값 그대로. 저장 흐름(계약 장부 연결·되돌리기·미저장 보호)은 기존 함수 그대로.

## 수용 조건
- [x] 미팅 창: 머리(업체명 · 날짜 시각–끝 · 장소 · 채널/예약 점 · 결과 입력 필요) → 업체정보|길찾기 → 결과 4칸 → 입력칸 → 보라 저장 버튼. 창 재질·크기 = 시안 `.pop`.
- [x] 계약 = 수임비·메모(계약조건) 저장, 계약일 칸은 미팅 날짜를 읽기 전용으로 보여 준다(앱 규칙). 완료·취소 = 사유 회차 누적, 계약에서 바꾸면 장부 삭제 확인. 변경 = 새 날짜·시각 검증 뒤 기존 변경 함수.
- [x] 결과가 난 미팅 = 요약 상자 + 되돌리기·추가 미팅, 계약은 「결과 고치기」. 예약은 「일정·업체명 고치기」로 기존 자동 저장 입력칸·삭제.
- [x] 트레이닝 목표 판 = 정량 5개 막대(달성 초록)·달성 수, 정성 PT 과제 번호 목록, 접힌 요약.
- [x] 목록 화면(1280px 미만) 미팅 카드는 #1424 이전 모양으로 되돌림(`boardTools` 제거).

## 시안에 있지만 넣지 않은 것
- 완료의 「다음 연락일」·「가망도」: 미팅 기록에 저장할 칸이 없다(새 DB 칸·마이그레이션 필요 — 별도 결정).
- 계약일 직접 고치기: 앱 규칙이 「계약일 = 미팅 날짜」라 읽기 전용.

# 미팅예약 → STEP 3 보장 (2026-11-08 belie)

## 원인 (코드 실측)
- 컨택결과 「미팅예약」의 저장값은 `컨택진행`(2026-10-23 이름만 바꿈, `lib/types/db-sheet.ts` DB_SHEET_RESULT_LABELS). 고르면 **결과만** 저장되고 미팅은 만들어지지 않았다.
- 미팅은 오른쪽 「미팅예약」 칸의 [예약 등록](`registerDbSheetMeeting`)을 눌러야 생기고, 도달 STEP 3 은 미팅이 이어져야 된다(`stepStage`).
- 그래서 「미팅예약 선택 + 날짜·시간만 입력 + [예약 등록] 안 누름」, 표에서 바로 미팅예약 선택, 소재지가 비어 버튼이 꺼진 경우 모두 STEP 2 에 머물렀다.

## 변경
- [x] 서버: 화면 경로(`executeDbSheet` contact)에서 미팅 없는 미팅예약 저장을 막음(`DbSheetMeetingRequired` = OperationBlocked → 409 + 안내 문구).
- [x] 직접 입력: 미팅예약을 고르면(상세·표 칸 모두) 결과만 저장하지 않고 미팅예약 칸을 연다. 날짜·시간·소재지가 차면 1.2초 뒤 스스로 [예약 등록] — 등록이 결과(미팅예약)까지 함께 저장. 이번에 날짜·시간을 직접 채워도 같다.
- [x] 녹음 정리 확정: 미팅을 먼저 등록하고 그다음 컨택 기록. 미팅 없이 미팅예약은 400.
- [x] 예전 줄: 도달 STEP 칸에 「일정 미등록」(주황). 열면 미팅예약 칸이 펼쳐져 「[예약 등록]을 눌러 주세요」 — 일별 기록에 따로 잡은 미팅과 겹칠 수 있어 자동 등록은 하지 않는다.
- [x] 시험: 패널 자동 등록 4 · 저장소 차단 1 · 통화 확정 순서·차단 · 분류 「일정 미등록」.

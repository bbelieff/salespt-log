# fix: UI/UX 1차 — 데이터 안전

## 목표
점검 보고서 1차 묶음(belie 「1차 진행」 2026-11-10). 기능 추가 없이 사고로 이어지는 조작만 막는다.

## 수용 조건
1. 탭 신원 차단막(IdentityGuard)이 모든 모달(z-[300]~[350])·로딩(z-[400])·팝오버(z-[500]) 위(z-[600]).
2. 컨택 화면 새 미팅 카드 ✕: 시간·업체명·장소·비고·업체정보 중 적은 게 있으면 확인. 빈 카드는 바로 삭제.
3. 새소식 팝업: 배경 탭으로 닫히지 않음(✕·확인만 = 읽음 처리).
4. `/login`: auth.ts `pages.signIn`·구글 캘린더 콜백이 보내는 곳. `/` 로 넘기고, 목적지는 경로만 꺼내 safeLoginReturn 재검증, 오류면 로그인 화면에 한 줄 안내.
5. 적던 내용이 사라지던 창 4곳
   - DB 가져오기: Esc — 붙여넣은 글·시트 주소·배치 결과가 있으면 확인.
   - 통화 정리 확인: 「나중에」·뒤로 — 고친 게 있으면 확인.
   - 해지 창: 사유·반환 방식·숨김 중 바꾼 게 있으면 배경 탭으로 닫히지 않음.
   - 일반 일정 안내창: 「돌아가기」 추가(입력 유지).
- 회귀 시험: tests/components/ux-batch1-data-safety.test.ts, tests/components/identity-guard.test.ts.

# 안드로이드 앱 시작 화면과 첫 로딩 화면 잇기

- 목표: 안드로이드에서 홈 화면 아이콘으로 열 때 로딩 화면이 두 번(시스템 시작 화면 → 우리 로딩) 다르게 보이는 문제 완화. 사용자 확인: 「아이콘(앱)」으로 열 때.
- 원인: manifest 에 아이콘이 없어 시작 화면이 기본 모양으로 뜨고, 이어서 회색 자리 표시 위에 반투명 로딩 창이 겹쳐 보였다. 시스템 시작 화면 자체는 안드로이드가 강제하므로 없앨 수 없다.
- 변경: manifest 아이콘 192·512·maskable(아이폰과 같은 빨간 $), 배경 흰색 유지. 앱을 연 뒤 첫 로딩만 흰 바탕 로딩 창(뒤 화면 안 보임), 그 뒤 로딩은 기존 반투명.
- 수용: 시험 tests/components/android-launch-splash.test.ts. 실제 안드로이드 기기 확인은 사용자.

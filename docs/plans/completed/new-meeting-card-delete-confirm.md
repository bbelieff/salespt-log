# 새 미팅 카드 삭제 확인 (2026-11-10)

## 목표 (belie 2026-11-10, UI 점검 보고서 1-2 「진행」)
「예약 등록」 옆 「✕ 삭제」를 잘못 누르면 업체명·장소·업체정보가 되돌릴 수 없이 사라지고 미팅예약이 1 줄었다. 저장된 카드는 이미 확인을 묻는다.

## 수용 조건
1. 업체명·장소·시간·비고·업체정보 중 하나라도 적혀 있으면 「적던 미팅 카드를 지울까요?」를 묻는다. 「돌아가기」·Esc·바깥 누르기 = 지우지 않음, 「카드 지우기」만 지운다.
2. 빈 카드는 지금처럼 바로 지운다.
3. 컨택 −버튼(마지막 새 카드 줄이기)과 저장된 카드 삭제 흐름은 그대로.

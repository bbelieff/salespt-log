# DB 가져오기 — 상담 신청 표·구글시트 주소 (2026-10-24 belie)

## 문제
1. 같은 엑셀을 제목행째 붙여넣으면 사업자번호가 「확인 필요」로 나옴 — `사업자번호`·`접수시간`·`신용700`·`국세체납`·`연매출액`·`비고` 머리글을 몰라 제목행으로 판정하지 못함.
2. .xlsx 파일은 날짜 형식 `yyyy. m. d am/pm h:mm:ss` 에서 표시 형식 해석이 실패해 파일 전체가 안 읽힘, 큰 사업자번호가 `1.0E9` 지수 표기로 읽힘.
3. 구글시트에서 복사하면 전화번호 칸이 두 개(중복 머리글 오류), `#REF!` 반복 제목행, `p:+8210…` 번호, `오후` 날짜.
4. 구글시트 공유 주소로는 가져올 수 없음.

## 바꾼 것
- 머리글 별칭 추가 + `신용700` 같은 「신용+숫자」 = 신용. 신용 예/아니오 → 「700점 이상/미만」, 체납 예/아니오 → 있음/없음, 날짜 앞부분만 YYYY-MM-DD.
- 제목행 판정: 전화번호 + (이름·업체·사업자) 머리글이면 제목행.
- 반복 제목행·오류값(`#REF!` 등)만 있는 줄은 건너뜀, 오류값 칸은 비움.
- 같은 칸이 두 번 나오면 처음 값을 쓰고, 다른 값이면 메모에 「머리글: 값」으로 남김(같으면 생략).
- xlsx: 칸 형식이 날짜면 머리글과 상관없이 날짜, 지수 표기 정수 → 숫자 글, 표시 형식 해석 실패 시 원래 값.
- 구글시트 주소: `lib/util/google-sheet-url.ts`(주소 판별) → `lib/repo/google-sheet-export.ts`(CSV 내려받기 — docs.google.com·googleusercontent.com 리다이렉트만, 10초·5MB 제한, 비공개면 공유 안내) → `lib/service/db-sheet-import-url.ts` → `POST /api/db-sheet/import-url`(로그인 필수, 저장 안 함). 화면은 입력칸에 주소를 넣으면 내려받아 붙여넣기와 같은 길로 분석.

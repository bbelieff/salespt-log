# 실무/수납 확정 목업 운영 이식 (2026-09-27)

## 목표

- `/payment`의 PC 화면을 확정 목업의 마스터·디테일 작업공간으로 이식한다.
- 기존 모바일 아코디언, 권한, 계약/수납 계산, 자동 저장, 캘린더 연결을 보존한다.
- 추가 필드가 Postgres `sheet_rows.payload` JSONB와 시트 미러에서 왕복 보존되게 한다.
- 검사, 병합, 운영 배포, 라이브 확인까지 완료한다.

## 구현 범위

- 성과 요약: 기간 조회, 계약/매출 강조, 업무 상태 5단계 단일 바, 업체/진행 바로가기.
- PC 마스터·디테일: 업체 카드 목록, 강한 선택 상태, 연결 그라데이션, 독립 스크롤, 가변 열 폭.
- 상세: 업체정보 우선, 계약정보/서류/로드맵/실무진행 순서와 접기, 편집 모달.
- 데이터: `계약비고`, 슬롯 `진행상품`, Todo/History 구분 및 15분 단위 시간.
- UI: 플러그 이관 제거(저장된 과거 값은 호환 보존), 메모 자동 높이, 진행기관 3.5 : 상품 6.5.
- Todo/History: 빠른 입력 후 상세 팝업, 캘린더 기본 연결, 양방향 동일 레코드 사용.

## 롤백

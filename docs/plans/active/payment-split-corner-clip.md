# 가라앉은 칸 모서리 잘림

- 원인: 두 칸 모두 `border-radius: 0.875rem` 였는데 칸 자체가 스크롤 상자(overflow auto)라 안쪽 내용이 그 둥근 모서리로 잘린다. 떠오른 칸은 안쪽 여백이 있어 괜찮지만, 가라앉은 칸은 여백 없이 카드가 칸 끝에 닿아 첫 카드(업체정보·계약정보) 좌상단이 늘 깎였다.
- 조치: 둥근 모서리를 떠오른 칸에만 준다.
- 확인: 합성 화면 1440px 2배 캡처, 양쪽 상태에서 가라앉은 칸 border-radius 0 측정.

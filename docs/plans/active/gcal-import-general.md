# 구글 캘린더 → 경영일지 일반 일정 가져오기 (2026-11-21 belie)

## 결정
- belie 「구글캘린더에서 일정을 입력하면 경영일지에 기록되는 건 막아놨었는데 이제 풀어줘」. 실제로는 스위치가 아니라 2026-07 설계가 앱→구글 단방향이라 반대 방향 기능이 없었다 → 새로 만든다.
- 들이는 방식은 belie 선택 **「일반 일정으로 저장」**(보여주기만 / 미팅으로 저장 대신). 일반 일정은 점수·통계에 안 들어간다.

## 동작
- 캘린더·일정 화면을 열면 `/api/gcal/import` 를 부른다. 같은 사용자 1분 안 재호출은 건너뜀. 본인 로그인에서만(대신 보기 중이면 건너뜀).
- 대상: 연결한 대상 캘린더의 오늘 기준 7일 전 ~ 90일 뒤. 반복 일정은 하루씩 펼쳐서. 한 번에 최대 200건 새로 만든다.
- 앱이 올린 일정(`extendedProperties.private.salesptId`)은 건너뛴다 → 미팅·할 일이 두 번 생기지 않는다.
- 새 일정 → 일반 일정(분류 「기타」, 업체명 빈칸). 제목·날짜·시각(서울 기준)·장소·메모(HTML 제거).
- 구글에서 고치면(수정시각이 바뀌면) 제목·날짜·시각·장소·메모를 구글 값으로 맞춘다. 앱에서 바꾼 업체명·분류·완료는 둔다.
- 구글에서 취소·삭제하면 가져온 일정을 휴지통으로.
- 가져온 일정에는 `gcalSource`(구글 일정 id·수정시각)를 DB 에만 남긴다. 이게 있으면 `todoToInput` 이 null → 앱이 구글로 다시 올리지 않는다(다시 올리면 중복이 생기고, 앱의 1시간 기본 길이로 원래 일정 길이가 잘린다).
- 앱에서 지우면 경영일지에서만 지운다(구글 일정은 그대로). 행 id 가 (이메일·캘린더·구글 일정 id) 해시라 다시 가져와도 같은 id → 지운 행과 부딪혀 되살아나지 않는다.
- DB 저장 기수만. 시트 저장 기수는 멱등 생성이 안 돼 건너뜀(지금 등록된 활성 기수는 모두 DB).

# 로딩 오버레이 — 중앙 'S' → 세일즈PT 로고 전체

- **상태**: 구현 완료 → PR 대기
- **트랙**: A (DevA) · 2026-07-15
- **브랜치**: `feat/loading-overlay-logo`

## 1. 요구 (belie, 2차 재지시가 정본)

- 가운데 'S' 글자 대신 **로고 전체**(심볼 $ + "세일즈PT" 워드마크)를 **원본 무가공**으로 — "살짝 작게 보여도 됨". 심볼만 크롭하는 안은 폐기.
- 색 함정: 로고의 "세일즈"·영문 글자는 **검정** → 다크 글래스 카드(`rgba(22,22,28,.72)`)에서 묻힌다.
- **belie 해법(정본)**: 에셋을 고치지 말고 **배경을 바꾼다** → 카드를 라이트 프로스트 글래스로.

## 3.5 적대적 리뷰에서 잡힌 결함 (5렌즈 × 반박검증, 2026-07-15)

- **HIGH — 궤도점이 PC 에서 링 밖으로 튄다 (기존 버그, 이 PR 이 악화 → 여기서 근본 수리)**
  `app/globals.css` 상단의 **PC 밀도 스케일**(`@media (min-width:1024px){ html{ font-size:13.5px } }`)
  때문에 rem 유틸이 84%로 줄어든다 → 링 `h-24`(6rem)은 **PC 에서 81px**. 그런데 궤도점의
  `transform-origin` 은 **px 고정**(구 42px / 본 PR 초안 50px)이라 원점이 링 중심보다 아래로 어긋나
  점이 링 밖(문구 위)까지 휘저었다. 링을 키우면서 이탈량이 커짐.
  **수리**: 회전 주체를 점(`::before`) → **부모 `.lo-orbit`** 로 이동. `.lo-orbit` 은 링과 동일 박스
  (`absolute inset-0`)라 기본 origin(50% 50%) = 링 중심 → **rem 스케일과 무관하게 항상 정확**.
  `prefers-reduced-motion` 셀렉터도 `.lo-orbit` 추가(안 하면 감속모션에서 점이 계속 돈다).
  실측 검증: PC(root 13.5px) 링 81px, orbit origin = (40.5, 40.5) = 링 정중앙 ✅.
  덤으로 tokens.md 에 "링 지름 96px" 같은 **PC 에서 거짓인 불변식**을 박제하지 않도록 rem 기준으로 표기.
- **MEDIUM(수용) — 링 안 로고 실효 크기 ≈ 72×24px(PC 61×21px)**: 워드마크 태그라인은 판독 불가.
  다만 **헤더 로고(`h-6`=24px)와 같은 급**이고 belie 가 "살짝 작게 보여도 됨"을 명시 → 그대로 간다.
  여백(`padding: 0 .75rem`)을 더 줄이면 호흡(scale 1.12) 때 로고 모서리가 링 스트로크에 닿는다(계산 확인).

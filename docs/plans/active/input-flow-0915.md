# STEP 1·2 채널 선택 흐름 (2026-09-15)

- 요청: 승인된 입력 흐름 목업을 실제 화면에 적용. 추가 확인/다음 버튼 없이 기록 대상이 명확해야 한다.
- 범위: DB생산 채널 미선택 진입, 채널 선택 즉시 추가 폼, 방문한 채널의 폼 유지. 컨택관리 날짜·채널 통합, 채널 변경 시 부모 초안 유지, 저장 날짜 표시, 세션 내 최근 채널 복원(명시적 URL 우선).

- 목업과의 의도적 차이: 날짜별 미저장 초안 캐시는 이번 변경에 추가하지 않는다. 날짜/주 이동 및 화면 이탈은 기존 DirtyGuard, 신규 미팅 저장 전 확인과 삭제 확인을 유지한다. 일반 채널 선택에 확인 모달을 추가하지 않는다.
- 검증: 실제 React 폼에서 채널 1클릭 진입, 숨겨진 DB 폼 복원, 교차탭 URL, 컨택 지표 채널 전환, 미저장 날짜 가드 테스트. 읽기용 fixture에서 반응형 확인. 저장소 check.sh 실행.
- 담당: Muse 구독이 독립 구현 위험/테스트 검토 초안 반환. GPT 구현·통합·검증. 기존 대기 변경과 파일 범위를 분리한다.

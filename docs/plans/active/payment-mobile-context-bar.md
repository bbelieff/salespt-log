# 모바일 업체명 줄 고정

- 원인: 폰(≤767px)은 저장 상태 줄(`data-payment-sticky-bar`)을 통째로 숨겼고(저장 알림은 위 오른쪽 떠 있는 알림), 업체 카드 머리는 스크롤로 사라진다. 진행건 제목(`payment-slot-head`)은 붙지만, 터치 기기에서 입력칸에 들어가면(키보드) 고정이 풀린다 → 편집 중엔 어느 업체·진행건인지 안 보였다.
- 조치: 그 줄을 폰에서도 보이고 왼쪽에 `업체명`(+ 입력 중인 진행건 「진행 N · 기관」 — 진행건 카드의 `data-slot-label` 을 focus 때 읽음)을 넣는다. 줄 안 상태 글만 폰에서 숨김. 섹션 제목 top 은 태블릿과 같은 app-content + 1.5rem.
- 키보드 상태 규칙(제목 고정 풀기)은 그대로 — 이 줄은 그 규칙 대상이 아니라 남는다.
- 확인: 합성 화면 390px — 스크롤·메모 칸 포커스 상태 캡처.

## 제안·목업
1. 모바일 동일 3행을 유지하고 padding7px/12px, 행 간격2px. 업체명14px·연락처12px 유지. 실제 높이/한 화면 표시량 비교.
2. 등록 미팅의 주 버튼 ‘STEP 3 · 미팅 일정 변경 →’. 기존 날짜·시간과 업체까지 바로 연결. 업체정보 편집은 별도 보조 동작 보존해야 함.
3. 삭제는 보조 ‘미팅 삭제…’. 확인창 첫 선택은 ‘일정 변경하기’; 실제 삭제 선택과 명확히 구분.
4. 삭제 직후 되돌리기 + ‘삭제한 미팅’에서 나중에 복원. 목업은 메모리 상태만 사용하며 운영 저장/복구는 구현 전.
5. 미팅 취소(고객이 취소, 이력 유지)와 잘못 입력한 카드 삭제 구분. 연결 계약/후속 미팅이 있으면 영향 목록 확인 후 진행하고 단일 예약과 같은 복구를 약속하지 않음.

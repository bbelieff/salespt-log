# 진행 단계 분류·정렬 (2026-10-26 belie)

belie: 「진행 단계도 오름내림차순」 → 「재통화 이하는 1.5 step, 미팅예약이나 컨택진행(컨택 후 거절)은 2 step, 진행 단계 분류 잘해줘」.

- 분류 = 가장 멀리 간 단계 하나: 계약 연결 → STEP 4 실무/수납 · 미팅 연결 → STEP 3 일정 · 컨택결과 미팅예약(컨택진행)/컨택 후 거절(상담 후 거절) → STEP 2 컨택관리 · 그 밖(미컨택·부재·단순거절·재통화·AS신청) → STEP 1.5 DB관리시트.
  - 판단: 미팅예약이라도 일정에 미팅이 연결돼 있으면 STEP 3(그 미팅으로 바로 감). AS신청은 「재통화 이하」 쪽(1.5)으로 둠.
- 표시: 1.5 = 회색 글자(이 화면이라 링크 없음), 2 = 보라 + 컨택관리로 이동, 3·4 = 기존 파랑 링크 + 상태.
- 정렬: 제목 클릭 → 내림차순(4→1.5) / 다시 클릭 오름차순. 단계 안에서는 컨택결과 순서 / 미팅·계약 진행 순서(미팅예약→미팅완료→계약→실무진행→수납대기→완료→장기관리→진행종료).
- 확인: 합성 DB관리시트에서 제목 정렬(aria-sort descending)·5행 모두 STEP 1.5 표시. 단계별 분류·정렬 순서는 `tests/components/db-sheet-grid-selection.test.ts`.

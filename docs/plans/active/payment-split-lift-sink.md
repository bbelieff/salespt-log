# 뜨고 가라앉기

- 넓힌 칸: `translateY(-4px)` + 테두리 1px + 큰 그림자 → 종이가 떠 있는 느낌.
- 좁힌 칸: `translateY(3px) scale(.985)` + 안쪽 그림자 + `#e2e8f0` → 파인 홈. 안의 흰 카드는 연회색·그림자 없음, 입력 칸·버튼은 흰색.
- 마우스·포커스가 들어가면 제자리. 0.26초 전환. 움직임 줄이기 설정이면 이동 없이 색·그림자만.
- 확인: 합성 화면 1440px 캡처(넓힌 칸 윗변이 좁힌 칸보다 높이 뜨는지).

# DB 가져오기 — 메타 추정·메모 (2026-10-26)

belie: 「매입DB 유형에 공급처를 다 적었는데 직접생산에 메타광고로 잡혀서 등록」「엑셀·구글시트·텍스트에서 메모가 있으면 상담메모로」.

## 원인
`parse()` 가 `created_time`·`lead_id`·`ad_id` 같은 열을 보면 줄마다 `공급처=메타 광고, 유형=직접생산` 을 박았다.
가져오기 창 「없는 공급처 채우기」는 **빈 공급처만** 채우므로 사용자가 적은 공급처가 무시됐고, 유형을 「원문 유형 유지」로 두면 직접생산이 그대로 저장됐다.

## 바꾼 것
- 메타 양식이면 줄의 유형·공급처를 비우고 **공통 칸(유형·공급처)에 「직접생산 · 메타 광고」를 채워 보여 준다** — 바꾸면 전체에 그대로 적용.
- 머리글 메모·한줄메모·비고·상담메모·상담내용·특이사항·요청사항·문의내용·메모사항 → **상담메모(contact.note)**. 열이 여럿이면 「머리글: 값」 줄로. 그 밖의 모르는 열은 지금처럼 원본 메모.
- 제목행 없는 붙여넣기의 「메모: …」 줄, 직접 열 연결의 「상담메모」 선택도 같은 칸으로.

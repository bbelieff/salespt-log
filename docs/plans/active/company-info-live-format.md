# 업체정보 입력 서식 (2026-09-29, belie)

- 금액 칸(백만원): 숫자 뒤 "백만원"(칸 안 오른쪽, 연도별 매출 표 포함), 입력하는 동시에 천 단위 쉼표. 옛 자유 글엔 단위·서식 안 붙임.
- 임차 보증금·월세(원): 입력하는 동시에 쉼표. 면적(㎡)은 그대로.
- 사업자등록번호: 입력하는 동시에 000-00-00000(숫자 10자리까지). 숫자 아닌 글은 그대로.
- 커서: "커서 앞 진짜 글자 수" 로 새 자리 계산 → 그린 직후 setSelectionRange. 쉼표·대시만 지우면(Backspace) 그 앞 숫자를 지운다.
- 업체정보 헤더 「편집」 → 「팝업」(누르면 팝업이 열린다).
- 되돌리기: squash revert. 저장 값 모양은 예전 blur 서식과 같아 데이터 영향 없음.

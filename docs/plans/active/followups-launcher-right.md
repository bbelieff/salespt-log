# 빠른 보기 우하단 (2026-10-24 belie 「비서 플로팅 아이콘은 우측하단으로 이동」)

- 위치: 모바일 탭바 위 오른쪽 16px · PC 오른쪽 24px(안전영역 더함). 창은 버튼 위 오른쪽 정렬, 원형 펼침 기준점도 오른쪽 아래로.
- PC 실무/수납(1280+)의 버튼 가림 여백을 목록 → 상세 칸 아래로 옮김(버튼이 이제 오른쪽).
- 문서·주석·시험 이름 「좌하단」 → 「우하단」.
- 확인(합성 미리보기): 375·1280px 버튼 우하단, 창 버튼 위 오른쪽 정렬, 가로 넘침 없음.

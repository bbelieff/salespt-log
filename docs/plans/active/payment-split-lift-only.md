# 넓힌 칸만 크게 떠오르기

- belie: 좁힌 칸을 회색으로 하니 흰 입력 칸만 남아 오히려 필드가 강조됐다. 열 전체를 어둡게 하면 「못 쓰는 칸」처럼 보인다.
- 그래서 좁힌 칸은 아무것도 바꾸지 않고, 넓힌 칸만 `translateY(-12px)` + 진한 바깥 그림자. 한 가지 신호(깊이)만 크게.
- scale 미사용(1px 테두리·둥근 모서리 뭉개짐 — 「테두리 사라짐」 신고의 원인 중 하나). 들림·그림자 잘림 방지 위아래 여백 14/28px.
- 떠오른 칸에만 안쪽 여백(10~12px) — 테두리가 안의 카드 테두리와 겹치지 않게(belie). 좁힌 칸에 주면 「업체정보」 제목이 잘려 제외.
- 확인: 합성 화면 1440px 2배 캡처.

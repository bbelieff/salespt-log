# 업체 계정 보관함 (belie 2026-10-08)

## 결정
- 수강생이 고객 아이디·비번·계좌·주민번호 전체를 관리해 주므로 보관이 핵심 기능이다.
- PIN 하나(4~8자리, 수강생이 정함). 한 번 열면 모든 업체 보관함이 10분 열린다(쓸 때마다 연장).
- 암호화 저장 + 시트 미러 제외. 열람 기록·열람자 제한은 두지 않는다(belie).

## 단계
1. [이번] 보관함 저장·PIN·열림 + 업체정보 편집기 안 「계정 보관함」 섹션.
2. 미팅 메모(txt)에서 업체정보·계정 뽑기 — 계정/비번/계좌/주민번호 뒷자리는 보관함으로.
3. 기존 기타메모 등에 적힌 비번·계좌·주민번호를 보관함으로 옮기기.
4. 업체정보 보기(전체/적은 것/안 적은 것) + 연도별 매출 가로 배치.

## 검증
- 단위 테스트(합성 데이터): 암호화 왕복·변조 거절·PIN·열림표·잠금·초기화.
- check.sh · CI · 배포 success · health 200. 화면은 운영에서 GM 계정으로 확인.

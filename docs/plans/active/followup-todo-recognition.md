# 챙길 일에서 안 사라지는 할 일 (belie 2026-10-23)

## 증상
수강생 A 가 실무/수납에서 업체 1·2·3 에 새 Todo 를 잡았는데 대시보드 「오늘 챙길 일」에서 그 업체가 안 사라졌다.
다른 업체는 사라졌다.

## 원인 (운영 DB 읽기 전용 확인, 2026-10-23)
- 남아 있던 줄은 **새 Todo 가 아니라 예전에 잡아 둔 미완료 Todo** 였다(「밀린 할 일」, 10/6·10/12 예정).
- 그 옛 Todo 의 기관 이름은 진행기관 칸을 고치기 전 이름이었다: 「소진공 혁신」·「소진공 일반경영안정자금」·「소진공 신취」.
  진행기관 칸은 지금 「소진공」이라 이름이 같지 않다. 진행건 번호(slot)도 없던 시절 기록이다.
- 그래서 `todoSlotOf` 가 어느 진행건에도 붙이지 못했고(slot=null), 실무/수납 진행건 칸 목록에 **아예 안 보였다.**
  대시보드는 계약으로만 묶어 계속 「밀린 할 일」로 띄웠다 → 수강생은 볼 수도 끝낼 수도 없었다.
- 새로 잡은 Todo(번호 있음)는 정상 인식됐다 — 「다음 할 일 없음」은 사라졌다. 사라진 업체/안 사라진 업체의 차이는
  「이름이 바뀐 옛 미완료 Todo 가 남아 있느냐」 하나다.

## 바꾼 것
- `todoSlotOf`: 번호 없고 기관 이름이 어느 진행건과도 같지 않은 옛 기록 → 기관 이름이 진행건 기관 + 공백으로 시작하면
  그 진행건(「소진공 신취」→「소진공」 진행건), 아니면 내용 있는 첫 진행건에 **「확인 필요」(ambiguous, reason=unmatched)** 로 보인다.
  화면에서 체크(완료)·삭제·「진행 N 기록으로」 지정이 된다.
- 추정 연결은 상태를 바꾸지 않는다: 대시보드는 여전히 「연결 진행건 확인 필요」, 업무 현황 「대기→진행」 판정에도 안 쓴다.
- 운영 데이터 무변경.

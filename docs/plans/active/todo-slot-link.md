# 기록을 진행건 번호로 연결 (belie 2026-10-23 [1])

- **원인**: Todo·History 와 진행건은 진행기관 이름으로만 연결됐다(`sameInstitution`). 진행 1·2 의 기관이 같으면 같은 기록이 두 진행건에 모두 붙었다.
- **바꾼 것**:
  - `Todo.slot`(1·2·3|null) 추가 — 시트 Q 열, DB payload. 진행건 칸에서 새로 적는 기록은 번호를 저장한다.
  - 판정 정본 `lib/analytics/todo-slot.ts` `todoSlotOf`: 번호가 있으면 그대로. 옛 기록(번호 없음)은 그 기관을 쓰는 진행건이 하나면 거기, 여럿이면 첫 진행건에 **한 번만** 보이고 「진행 N 기록으로」 버튼으로 바로 지정한다.
  - 진행건 칸 목록, 대시보드 「오늘 챙길 일」(옛 기록이 여러 진행건에 맞으면 지금처럼 「진행건 확인 필요」), 업무 현황이 같은 판정을 쓴다.
- **운영 데이터는 고치지 않는다**(읽을 때 판단). 옛 기록은 사용자가 버튼을 누를 때만 번호가 저장된다.
- **그대로**: 기관별 목록(기관 보기)의 활동일 색인은 기관 기준(기관 묶음 화면이라 의도대로).
- **검증**: `tests/components/todo-slot.test.ts`, 전체 단위 테스트.
- **되돌리기**: revert 1회. Q 열 값은 남아도 옛 코드가 읽지 않는다.

# DB관리시트 엑셀 파일 가져오기

목적: 파일 선택·끌어놓기에서 .xlsx와 .xls를 읽고 기존 검토/유입 선택으로 연결한다. 대상: 개발·검증 담당자. 관련: ImportDialog, xlsx.ts, components.md.

- 승인: 2026-10-15 사용자 “파일 끌어다놓으세요에 엑셀확장자에도 되도록 해”. 직전 운영배포의 파일 가져오기 후속 직접수정. 화면 구조는 유지하고 지원 확장자 안내만 보완한다.
- 기준: origin/master 32219da9, feat/db-sheet-excel-import. 총괄이 구현, 작성자와 다른 검증자가 최종 head 검토. 운영 실데이터 쓰기 없음.
- 발견: .xlsx reader/accept는 있으나 화면 안내에서 누락. .xls는 명시적으로 차단.
- 범위: .xlsx 기존 경로 유지, .xls 바이너리 읽기, 파일선택/드롭 공통 검증, 5MB 제한, 첫 시트 안내, 오류 메시지. 엑셀 라이브러리는 공식 SheetJS 0.20.3 배포본 고정(https://docs.sheetjs.com/docs/getting-started/installation/frameworks/).
- 수용: 실제 xlsx/xls(한글/전화/날짜/따옴표) 파일 → 기존 미리보기, 유입 기본체크·해제 보존. 다중 파일/과대/손상 파일 안내. 파일 내용은 저장 확인 전 DB에 쓰지 않는다. 기존 export 회귀 검사.
- 게이트: 집중시험, Git Bash check.sh, build, 실제 PC/모바일 화면, 독립검토, CI, 직렬 merge/deploy/health/live.

# 업체정보 편집기 재구성 (PR-6)

## 1. Scope (belie 요청 2026-09-28)

1. 섹션 순서 [대표자] → [기업정보](옛 [업체]) → [재무]. TXT 도 같은 순서.
2. [대표자]: 라벨 "주민등록번호"(앞 6자리만 저장 규칙 그대로, 예시 글 없음). 소유여부 = 기업정보와 같은 자가/임차 선택 + 임차 3칸(새 키 대표임차보증금·대표임차월세·대표임차면적).
3. [기업정보]: 사업자구분+과세유형 한 칸 조합 선택, 법인등록번호는 법인일 때만, 소유여부 자가/임차 + 임차면 보증금(원)·월세(원)·면적(㎡) 한 줄, 업종·업태·주생산품목 한 줄(새 키 주생산품목), 매출·기대출(사업자)은 [재무] 로.
4. [재무]: 연도 매출 "매출 Y(2026)" ~ "매출 Y-3(2023)"(오늘 기준 연도), 반기 매출 4줄×2칸(새 키 8개), 매출증가율 3칸(Y-3→Y-2 · Y-2→Y-1 · Y-1→Y, 자동 계산·저장), 기대출(사업자), 나머지 재무.
5. 저장: 새 15키 = 04 **BO~CC**(BN 바로 뒤) · 06 **AW~BK**(AV 바로 뒤). 기존 열은 한 칸도 옮기지 않는다.
6. 문서 자동입력: 부가세 → 반기 8칸(옛 반기별매출 안 채움), 임대차 → 소유여부 "임차"·보증금/월세 원 숫자·면적 ㎡ 숫자, 재무제표 → 매출증가율 안 채움.

## 3. 옛 값 보존 (데이터 손실 0)

| 칸 | 옛 값 | 화면 | 바꿀 때 |
|---|---|---|---|
| 사업자구분·과세유형 | "개인" + 과세유형 빈칸 | 고를 수 없는 "개인 · 과세유형 선택" 이 선택된 채 | 두 키 함께 저장 |
| 〃 | 목록 밖 자유 글("개인(공동대표)") | 글 그대로 선택지 | **자율결정**: 뜻이 옮겨지지 않는 옛 글은 기업정보 기타메모에 "이전 사업자구분: …" 로 덧붙임 |
| 소유여부·대표소유여부 | "임차 : 보 1000만, 월 50만" 등 | 선택 짐작(자가 포함→자가, 임차·월세·전세→임차) + 아래 "이전에 적은 내용: …" | **자율결정**: 원문을 해당 기타메모에 "소유여부 이전 내용: …" 로 옮긴 뒤 선택값 저장(말없이 지우지 않음) |

| 임차면적 | "33㎡(10평)" | 그대로, 단위 "㎡" 안 붙임 | — |
| 업종주생산품목 | "제조/필름" | 라벨 "업종" 칸에 그대로 | — |
| 반기별매출 | 여러 줄 | 입력칸 없음, 값 있으면 "이전 반기별 매출 메모"(읽기 전용) | 키·열 유지 |
| 매출증가율 | "12%" | 입력칸 없음, 값 있으면 "이전 매출증가율 메모"(읽기 전용) | 키·열 유지 |

- **자율결정 — 임차 칸 표시**: 선택이 임차일 때 + **임차 칸에 이미 값이 있으면**(선택이 비었거나 자가여도) 보인다 — 값이 있는데 숨으면 안 보이는 데이터가 생긴다. 법인등록번호는 지시대로 **법인일 때만**(숨겨도 저장값·TXT 유지).
- **해석 — "사업자등록번호도 법인으로 찍은 경우에 필드 나타나게"**: 개인사업자도 사업자등록번호가 있으므로 법인등록번호를 가리킨 말로 읽었다(사업자등록번호는 항상 보임).

## 4. 매출증가율 계산

- `lib/util/company-sales.ts`: 매출 글 → 원(백만·억·천만·만·천, 쉼표 숫자=원, 앞 "25'"·"2025년" 무시, "6월"·"1~6월"·"6개월" = 몇 월까지). 금액 덩어리가 둘 이상("25' 250백만 / 24' 148백만")·못 읽음 → 계산 안 함(빈칸).
- 결과 "+12.5%" / "-3.0%" / "0.0%"(소수 한 자리), 이전 해 매출 0 이하면 빈칸.
- **언제**: 편집기 `apply()`(직접 입력·선택·문서 자동입력이 모두 지나는 한 곳)에서 `withSalesGrowth` 로 3칸을 다시 계산해 **같이 저장** → 시트·TXT 에 들어간다. 화면 증가율 칸은 늘 현재 연도 매출로 계산해 보여 준다. 편집 전 옛 행은 다음 편집 때 저장된다(열기만 해서 자동저장이 돌지 않게 — 의도). TXT 내보내기는 `withSalesGrowth(draft)` 를 보내 편집 전에도 계산값이 들어간다.
- 올해 매출에 월이 있으면(12월 제외) Y-1→Y 설명(툴팁·sr-only)에 "올해는 N월까지 매출이라 낮게 보일 수 있어요".

## 5. 문서 자동입력

- 부가세: 반기 칸 = 올해~3년 전 상·하반기, 값만 `formatManwon`("1.2억"). 반기 전체가 아닌 신고(예정 1~3월)는 값 + 경고 + 확신도 0.6. 간이과세 연간·3년보다 오래된 반기는 연도 합계에만.
- 임대차: 보증금·월세 `groupThousands`("10,000,000", 반올림 없음), 면적 ㎡ 숫자 소수 한 자리(평만 있으면 ×3.3058), ㎡·평 병기는 참고 정보(저장 안 함). 소유여부 "임차".
- 재무제표: 매출증가율 제거(연도 매출 칸으로 편집기가 계산).
- 비교표 라벨·순서 = 편집기와 같은 `companyInfoFieldList(today)`.

- 시즌 = **A1**. 자기기수 = 입력 그룹의 N기.
- **시트명**: `세일즈PT_A1_{자기기수}기 {이름}_대표님 경영일지`
- **업체관리 폴더명**: `세일즈PT_A1_{자기기수}기 {이름}_대표님 업체관리`
- **레지스트리 cohort 라벨**(클레임 매칭 키): `A1-{자기기수}기` (예: A1-1기)
- **레지스트리 name**: 이름 그대로. 부부면 `류서하(심나영)` 형태로 **두 이름 모두 저장**.

## 3. 특수 표기 처리 (확정)
- **부부 `(괄호)`** = 1인 1시트. 시트/폴더 제목에 **두 이름 다**(`류서하(심나영)`). 레지스트리 name에도 두 이름 저장 →
  **클레임 시 입력 이름이 둘 중 하나와 일치하면 인식**(matcher `lib/repo/name-match.ts`: 저장값 → {전체, 앞, 뒤} 후보, 입력 ∈ 후보. `findExistingSheetIdByCohortName` + `claimRegistry` 양쪽 적용. ADR-0014).
- **회장 `★(*)`** = 레지스트리 **메모 컬럼에 "회장" 기록만**(앱 기능 없음). users 탭에 메모 컬럼 Q 추가(없으면).
- **입금 `💰($)`** = 레지스트리 **메모에 "입금" 기록만**.
- 메모 형식 예: `회장,입금` / `입금` / `회장` / 빈값.
- **멱등(명단 계속 업데이트)**: (cohort=A1-N기, 이름) 이미 등록·시트 존재 시 SKIP. 신규만 생성.

# 화석 코드 정비 A3 — 낡은 주석·문구 정정

- **"편집 가능 기간 / 편집기간" → "시트 좌표 범위"** (6개 파일): 편집 제한은 ADR-0031 로 폐지됐고, 남은 1~10주 한계는 시트 물리 좌표일 뿐이다. 로그·Sentry 오류 문구도 같이(`sales.ts` — 테스트 갱신).
- 8주 고정이라고 적힌 곳(주간 차트·대시보드 주간 배열) → "기수 통계 창(8 또는 12주)". 누적수임비만 시트 B21 과 맞추려 8주 고정인 이유를 정확히.
- `lib/config/index.ts` 시트 구조 설명의 "02·03 앱 사용 X", "수납은 01 실적관리 칸" → 지금 구조(앱이 쓰고 정본은 DB).
- `db/client.ts` "수동 마이그레이션 불필요" → 새 스키마는 번호 파일로(scripts/db-migrate.mjs).
- `identity.ts` "11주+ throw(후속 wave)" → DB 경로로 저장(이미 구현).
- 대시보드 KPI 타입 주석의 시트 셀 좌표(D21·E21·TODO) → 실제 계산 기준.
- 부가세여부 "H열" → 매입DB F열(ADR-0021).
- **화면 문구 1곳**: 아레나 순위표 매출 탭 설명 "대시보드 총매출" → "아레나 매출(시즌 시작 이후 · 이월 제외)" — 대시보드 매출은 이제 기간 기준이라 값이 다르다(ADR-0034).
- 검증: typecheck, 컴포넌트·좌표 테스트, check.sh. 되돌리기: squash revert 1건. 계산·저장 동작 변화 없음.

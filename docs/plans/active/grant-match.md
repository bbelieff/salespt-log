# 맞춤공고 3단계 — 매칭 판정 (2026-10-26)

핸드오프 §2: 1차 = 지역 + 소상공인 여부 + 제외 업종, 나머지는 적혀 있을 때만, 모르면 「확인 필요」.

| 조건 | 안 맞음 | 확인 필요 |
|---|---|---|
| 마감 | 날짜 지남 | — |
| 지역 | 다른 시·도 / 다른 시·군·구 | 공고·업체 지역 모름, 업체 시·군·구 없음, 전국 공고의 지원대상에 다른 지역 |
| 소상공인(대상에 소상공인만) | 소상공인 아님 | 직원 수·대분류 모름 |
| 제외 업종 | 업체가 제외 업종 | — |
| 업종(공고가 좁힌 경우) | 다른 대분류 | 알 수 없는 업종 글, 업체 대분류 없음 |
| 업력 N년 이내/이상 | 어긋남(단일 조건) | 개업일 없음, 「자금별 상이」처럼 갈리는 글 |
| 청년 | — (여러 대상 중 하나로 적히는 일이 많아 단정 안 함) | 나이 모름·넘음 |
| 여성·장애인·수출·재창업·사회적기업 | — | 업체가 안 켬 |

급함(소진 임박) = 예산 소진형 또는 마감 7일 이내. `matchesFor` = 안 맞음 빼고 급함 → 맞음 → 확인 순.

## 엄격화(2026-10-26 belie)
- 업종: 공고가 업종을 좁혔고 업체 대분류를 알면 목록에 없을 때 **안 맞음**(모를 때만 확인). 제목·지원대상·특정타겟에 적힌 업계(관광·에너지·환경산업·문화콘텐츠·농림수산)도 업체 업태·업종에 그 업계 말이 없으면 안 맞음.
- 지원대상 지역 다름 → 안 맞음. 청년: 생년월일·주민번호 앞자리로 나이를 알면 넘을 때 안 맞음.
- 「소진 임박」 배지·우선 순위는 맞는 공고에만(확인 필요는 마감이 가까워도 확인 필요).
- 「경기 안산」처럼 시 뗀 지역도 시·군·구로 읽는다.

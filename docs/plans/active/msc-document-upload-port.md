# MSC report 서류 자동입력 → 경영일지 이식 (핸드오프)

보낸 곳: MSC report(원페이지경영진단 자동화시스템/리드디벨롭) 세션 · 2026-11-01
사용자 지시: "지금 문서업로드 시스템 점검하고 경영일지의 것보다 좋으면 경영일지에 핸드오프 전수해줘"

## Intent (왜)
두 앱의 「서류 올려 자동 채우기」를 같은 기준으로 점검했더니 MSC 쪽이 **읽는 서류 종류·스캔/사진 정확도·합본 처리·사무 파일 형식**에서 앞선다. 경영일지는 코드 구조(TypeScript 모듈·159개 시험)·취소/시간 제한·메모→계정금고가 더 낫다. 그래서 **경영일지의 구조는 그대로 두고, MSC 의 앞선 기능만 경영일지 `lib/document-ocr/` 에 옮긴다.**

## 2단계(선택, 사용자 결정 필요): 서버 OCR
- MSC 는 VPS 에 `deploy/msc-ocr/server.py`(PaddleOCR PP-OCRv4 검출 + PP-OCRv5 한국어 인식, RapidOCR/ONNX, systemd `msc-ocr.service`, 127.0.0.1:3410, Caddy `/ocr/*`)를 띄워 1.6초/쪽. 15MB·긴 변 2400px·한 번에 한 장, Supabase 로그인 토큰 확인(401), 사진은 저장하지 않고 로그엔 크기·시간·상태만.
- 경영일지에 쓰려면: ① 경영일지 로그인으로 인증하도록 서버에 인증 방식 추가(또는 경영일지용 별도 인스턴스) ② 화면 문구 「파일은 이 기기 안에서만…」을 「글자 읽기를 위해 사진을 우리 서버로 보냅니다(저장 안 함)」로 바꾸기 ③ 서버 실패 시 지금처럼 브라우저 OCR 로 대체.
- **같은 VPS 에 경영일지 운영(pm2 :3000)이 있다. 경영일지 운영 프로세스·포트는 건드리지 말 것.** 서버 OCR 메모리 사용량을 먼저 확인.

# 상담 중 = 실제 결과 기준 (2026-10-25 belie 「규칙 유지 + 표시만 분리」)

- 배경: 같은 날 미팅예약·컨택 후 거절 → 재통화·단순거절로 고치면 `db_sheet_contacts.qualified` 가 OR 로 남는다. 이건 실적 규칙(상담 후 같은 날 「다시 연락」이어도 실적 인정 — `db-sheet.pglite` 시험이 고정)이라 유지.
  그 표시가 현재상태까지 끌고 가 같은 단순거절·재통화가 「상담 중」/「DB컨택중」으로 갈렸다(김재원 5건 + 다른 수강생 1건).
- 수정: 현재상태의 「상담 중」은 기록에 남은 결과(`result` 가 미팅예약=컨택진행·상담 후 거절인 날이 있나)로 판정. 읽을 때(listDbSheet)와 컨택 저장 때 같은 기준. `hasQualifiedContact`(실적·퍼널)와 STEP 2 숫자는 그대로.
- 데이터: 무변경 — 읽을 때 다시 계산하므로 기존 6건도 바로 맞게 보인다. 컨택 기록이 없는 옛 행만 저장값으로.
- 시험: 같은 날 바꾸면 DB컨택중·실적 유지, 다른 날 실적 뒤 거절은 상담 중(pglite).

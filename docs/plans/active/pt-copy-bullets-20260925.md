# PT과제 복사 불릿과 줄바꿈
## Intent
지난주·이번주 PT과제를 과제당 불릿과 줄바꿈으로 구분하고 특이사항 작성 안내를 제공한다.
## Acceptance Criteria
- 지난 과제/성과 매칭과 빈 성과 위치 보존, 이번 과제도 단건부터 불릿 표시.
- HTML 셀 내부 줄바꿈, text/plain은 인용된 다중행 TSV로 줄바꿈 보존.
- 특이사항은 내용별 줄바꿈 안내, 입력 내용·자동저장·접근권한 보존.
- 기존14열 순서, 미리보기, 권한/복사 회귀 유지 및 전체 검사 통과.
## Steps
1. Muse 구현·회귀 초안, Codex 통합·검증.
2. PR/CI/배포/운영 확인.

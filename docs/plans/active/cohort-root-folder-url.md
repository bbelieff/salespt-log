# 기수 생성 — 루트 폴더 주소 허용

## 문제
2026-09-28 12기(5명) 생성이 전원 `File not found: .` 로 실패. 루트 폴더 칸에 공유 주소 전체가
들어갔고, 서버가 그 문자열을 그대로 기수 설정에 저장하고 드라이브 검색 조건(`'<값>' in parents`)에 넣었다.

## 수정
- `extractDriveFolderId`(순수 유틸): `/folders/<ID>`·`?id=<ID>`·ID 그대로 모두 ID 로.
- 생성 라우트: 설정 저장 전 폴더·시트 ID 정규화 + 이미 주소로 저장된 설정도 검색 시 정규화.

## 수용 기준
- [ ] 유틸 단위 테스트 통과, check.sh 초록
- [ ] 배포 success · health 200
- [ ] 같은 입력(주소)으로 12기 재실행 → 5명 생성, O1=2026-10-02 · O2=2026-12-19

## 되돌리기
PR revert. 저장된 기수 설정은 다음 실행 시 다시 덮인다.

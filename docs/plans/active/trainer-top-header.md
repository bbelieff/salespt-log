# 트레이너 최상단 접속 헤더

- 서버 접속 계정 → 공통 TopHeader; 대리접속 대상 표시와 분리.
- 본문 중복 헤더 제거. 공통 컨테이너·필터·타이포·간격 재사용.
- 기존 담당 카드·권한·경로·데이터 보존.
- 회귀: 헤더 계정/시트 분리, 단일 헤더, 수강생 기본 표시 보존, 담당별 진입 유지.
- 필수 check.sh 및 빌드, 배포 후 모바일·PC 헤더/넘침 확인.
- Muse: 실제 구독 검토 완료. 구현·통합·검증은 GPT. 향후 참조 파일 지침을 AGENTS.md에 기록.

# 공고매칭 칩 펼침 (2026-10-26)

계기: 운영에서 「공고매칭 2/3」을 눌러도 반응 없음(#1243). belie 승인(개발가이드 세션 전달): 「빈 조건으로 데려가기(지금), 매칭 후 맞는 공고 상자 열기(4단계)」.

## 지금
- 칩 = 버튼(접기 버튼 밖으로 옮김 — 버튼 안 버튼 금지). 펼침 세 줄: ✓ 지역 울산 남구 / ✓ 대분류 제조업 / – 규모: 4대보험 직원 칸이 비어 있어요 [채우기 →].
- 「채우기 →」: 접혀 있으면 펴고, 기본보기면 넓힌 보기, 거른 보기면 전체로 → 그 칸 스크롤·포커스. 대분류·규모(대분류 없음)는 업태 칸.
- 3/3: 「✓ 준비 완료 · 공고가 들어오면 맞는 공고를 보여 드려요」만.
- Esc·바깥 누르기 닫힘, Esc 는 칩으로 포커스 복귀.

## 4단계(매칭 뒤)
- 칩 「맞는 공고 N」 → 실무/수납 「🎯 맞는 공고」 상자 열고 이동. 실무/수납 밖(팝업 편집기 등)에서는 그 업체 실무/수납으로 이동 여부 판단.

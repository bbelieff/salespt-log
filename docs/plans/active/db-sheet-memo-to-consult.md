# 원본 메모 → 상담메모 · 지역(상호) 나누기 (2026-10-26)

belie(캡처): 원본 메모에 「메모: 서울송파구(소미아) / …」가 있는데 상담메모가 비어 있다 — 이 메모가 상담메모에 적혀야 한다. 「서울송파구(소미아)는 주소와 사업자명 같은데 알아서 구분해서 잡아줘」.

## 바꾼 것
- **읽을 때(저장 안 함)**: 상담메모가 비었고 원본 메모의 「[가져온 원문]」 앞에 메모 계열 줄(메모·비고·상담내용·특이사항·요청사항·문의내용 …)이 있으면 그 값을 상담메모로 보여 준다. 고치면 그때 저장된다. 상담메모에 이미 글이 있으면 그대로.
- **지역(상호)**: 메모 앞머리가 「서울송파구(가상상회) / …」처럼 시·도로 읽히는 지역 + 괄호 이름이면 비어 있는 주소(「서울 송파구」)·사업자명만 채우고 상담메모에는 뒤 본문만. 시·도를 못 읽으면 나누지 않는다. 가져오기(parse)에서도 같은 규칙.
- 한계: 사용자가 상담메모를 일부러 비우면 원본 메모 줄이 다시 보인다(원본 메모는 지우지 않으므로).

# 홈택스 PDF 자동입력 수정 (2026-09-29)

## 증상
belie 제보: 실제 부가세 과세표준증명 PDF → "채울 수 있는 칸을 찾지 못했어요 · 과세기간별 금액을 찾지 못했어요",
표준재무제표 PDF → 읽지 못함. 두 문서 모두 텍스트층이 있는 홈택스 발급 PDF(스캔 아님).

## 원인 (실제 파일로 로컬 재현 — 파일·내용은 레포에 남기지 않음)
1. `readPdfTextLayer` 가 텍스트 조각마다 줄바꿈 → 표 한 줄("기간 기간 금액 …")이 흩어짐. 조각 순서도 화면 순서가 아님.
2. 홈택스 과세기간 표기 `2023/01/01 2023/06/30` — 물결(~) 없음. 파서 RANGE 가 물결을 요구.
3. 텍스트층을 1쪽만 읽음 — 표준재무제표는 1쪽이 표지, 숫자는 2~6쪽.
4. 표준재무제표는 한 줄에 두 열 + 과목 코드(`Ⅰ.매출액 01 금액 9.가스.수도비 30 금액`) — 오른쪽 열 과목(자산총계·이자비용)을 못 찾고, 옆 과목 금액을 전기 매출로 붙임.

## 수정
- `lib/document-ocr/pdf-lines.ts`(신규, 순수): 같은 높이(±2pt) 조각을 한 줄로, 위→아래·왼→오른. 쪽 사이 빈 줄.
- `ocr-pdf.ts`: 텍스트층을 `OCR_LIMITS.pdfTextMaxPages`(10)쪽까지. 스캔 PDF(OCR 폴백)는 그대로 첫 쪽.
- `parse-vat.ts`: RANGE 가 공백만으로 이어진 두 날짜도 기간으로.
- `parse-fs.ts`: 표준재무제표(`표준재무|표준손익|표준원가`)일 때만 두 열 분리(`splitItemColumns`) + 금액 앞 두 자리 코드 제거. 로마 숫자 계산식 괄호 `(Ⅰ+Ⅱ)` 제거.
- 팝업 안내 "PDF 는 10쪽까지(스캔본은 첫 쪽) 읽어요".

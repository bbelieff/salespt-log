# 실무/수납 Todo 고치기 외 4건 (2026-10-27 belie, 휴대폰 스크린샷)

1. **Todo 고치기**: 제목을 누르면 「자세히」 창이 수정 모드로 열려(만들기와 같은 모양) 제목·날짜·시각·종류·상세·캘린더 표시를 고친다. 저장 = 기존 PATCH(/api/todos/[id]) — 새 API 없음. 종류(Todo↔History)는 서버가 못 바꿔 탭을 숨김. 목록 밖 시각(14:20 등)도 유지.
2. **진행건 기본 접힘**: `PaymentSlotForm` 시작 상태 = 접힘. 예외: 캘린더·알림 링크(focusPayment)·진행기관 목록에서 고른 진행건(autoOpen), 「진행 추가」로 만든 빈 진행건. 업체를 열 때 대표 진행건을 자동으로 펼치던 대체값(page.tsx) 제거.
3. **휴대폰 「+ 다음」 버그**: 원인 = 입력칸이 바깥 누르기(blur)로 닫혔는데, 휴대폰은 달력을 열 때 초점이 빠져 제목이 비어 있으면 닫히고 초기화. → blur 닫기 제거, 저장·취소 버튼 추가(Enter·Esc 유지).
4. **Todo 칸 줄이기**: 기록 한 줄(체크·제목·날짜·×) — 「Todo」 배지(체크박스와 중복)·「기타」 종류 배지 제거, 아래 줄은 결과·+다음이 있을 때만. 기록마다 치던 상자 → 흰 판 하나 + 줄 구분선. 추가 칸 3줄 → 2줄, 안내 문구 한 줄로.
5. **「자세히」 날짜 칸**: 날짜·시·분을 4열 격자(날짜 2칸)·같은 높이(h-10)·`min-w-0 appearance-none`(iOS 날짜 칸이 폭·높이를 무시하던 것).

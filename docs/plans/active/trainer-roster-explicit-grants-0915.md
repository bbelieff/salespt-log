# 트레이너 권한 대상 명단과 수동 권한 설정

## Intent
사용자 요청: 권한부여 대상은 활동 중인 트레이너 전체 중 관리자·관리부서를 제외한다. 기존 저장 권한을 유지하며 신규·등급 변경 시 자동 체크를 제거한다. 수강생 모든 탭에는 대시보드 복귀 링크를 유지한다.

## Acceptance Criteria
- [x] 자격 테이블에 없는 기존 등록 트레이너도 조회한다. 자격 행이 있으면 기존 등록보다 우선한다.
- [x] 관리자·관리부서·비활성 계정을 조회와 저장 모두에서 제외한다.
- [x] 조회는 데이터를 변경하지 않는다. 기존 등록자의 첫 명시 저장에서만 자격을 가져온다.
- [x] 기존 저장 권한 보존, 신규·등급 변경 시 자동 부여 없음.
- [x] 수강생 헤더 복귀 링크는 트레이너 조회 실패와 독립적이다.
- [ ] 전체 필수 게이트, CI, 운영 배포 및 실제 명단 대조.

# 당겨서 새로고침 ↔ 안쪽 스크롤 (2026-10-24 belie 「모바일 위아래 스크롤이 잘 안 됨」)

## 원인
당겨서 새로고침은 **페이지**가 맨 위(scrollTop=0)면 아래로 끄는 손가락마다 `preventDefault` 를 건다. DB관리시트·실무/수납처럼
높이를 고정하고 안쪽 목록이 스크롤되는 화면은 페이지가 늘 맨 위라, 안쪽 목록을 위로 올리려는 손가락이 전부 막혔다
(아래로 내리기는 되고 위로 올리기만 뻑뻑함). 같은 터치 안에서 먼저 위로 밀었다가 되돌아올 때도 막혔다.

## 수정
- 터치 지점의 조상 중 세로 스크롤 영역이 맨 위가 아니면 새로고침 제스처를 시작하지 않고, 움직이는 중에도 그런 상태면 막지 않는다.
- 페이지·목록 모두 맨 위에서 끌면 기존처럼 새로고침.

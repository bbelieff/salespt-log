# 신규 작업원 온보딩 핸드오프 (복붙용)

## 왜 필요한가 (2026-08-05 실측 사고)
새 세션이 맥락 없이 투입되면 반복적으로 같은 데서 막혔다:
- 로컬에 토큰이 없어 `invalid_grant` 을 2회 헛짚음 (정본 경로는 VPS)
- 새 워크트리에 `node_modules` 가 없어 `check.sh` 사망
- Linear MCP 연결 여부를 몰라 도장을 못 찍음
- 자기 구역이 어딘지 몰라 남의 레인 침범 / 또는 전부 반려
- 이미 끝난 일(토큰 등록)을 belie 에게 다시 요청
- **일하고 있는데 대시보드엔 「대기」로 표시** — 하트비트가 없어서

→ **아래 템플릿 하나로 전부 선차단한다.**

P7 제출 전 4렌즈 자기공격 — 정확성 / 완결성 / 파급 / 되돌리기
   발견한 문제는 숨기지 말고 보고에 함께 적는다

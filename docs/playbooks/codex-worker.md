# 제작 · 목업·구현
> **요약**: [workflow](../development/workflow.md)의 목업·구현 담당. 독립 검증은 [검증 담당](codex-reviewer.md)에게 반환한다. [AGENTS](../../AGENTS.md)·[CLAUDE](../../CLAUDE.md).

- 직접 요청/유효 배정의 목표·범위·수용조건·base·작업 폴더를 확인한다.
- 병렬 배정은 좁은 파일·선행조건·검수자·반환처 ACK 후 범위 안에서 편집한다.
- 최신 코드·PR에서 이미 구현됐는지 확인한다. 옛 문자·이슈 번호로 소유를 추정하지 않는다.
- 실제 컴포넌트·CSS·폰트·토큰을 재사용한 합성 목업·직접 열 수 있는 링크·비지원 범위를 반환한다.
- 승인 전 의존 구현·운영 반영을 멈추고 승인본을 보존한다. 승인 후 UI 코드를 이어 구현하며 독립 검증의 재현·기대값으로 수정한다.
- 메인은 읽기 전용, 구현은 전용 worktree. 기존 변경·타인 자원·실데이터 보존.
- check.sh·필요한 build·현재 CI·UI 실화면 검수.
- 총괄/선언된 배포 책임자에게 반환한다. 자신이 배포 책임자인 경우만 직렬 squash → 해당 배포 success → 공개 health 200 → 안전한 live 확인.
- 변경 파일·SHA/run·PASS/FAIL/NOT_RUN·위험·미완료/다음 행동을 반환한다.
- 새 비용·권한·정책·비가역 데이터·외부 발행의 차이만 확인한다. 일반 단계 재승인 금지.

# 구현·검증 담당
> **요약**: 맡은 변경을 운영 확인까지 완주한다. [AGENTS](../../AGENTS.md)·[CLAUDE](../../CLAUDE.md).

- 직접 요청/유효 배정의 목표·범위·수용조건·base·작업 폴더를 확인한다.
- 병렬 배정은 좁은 파일·선행조건·검수자·반환처 ACK 후 범위 안에서 편집한다.
- 최신 코드·PR에서 이미 구현됐는지 확인한다. 옛 문자·이슈 번호로 소유를 추정하지 않는다.
- 메인은 읽기 전용, 구현은 전용 worktree. 기존 변경·타인 자원·실데이터 보존.
- check.sh·필요한 build·현재 CI·UI 실화면 검수.
- 직렬 순서에 따라 squash → 해당 배포 success → 공개 health 200 → 안전한 live 확인.
- 변경 파일·SHA/run·PASS/FAIL/NOT_RUN·위험·미완료/다음 행동을 반환한다.
- 새 비용·권한·정책·비가역 데이터·외부 발행의 차이만 확인한다. 일반 단계 재승인 금지.

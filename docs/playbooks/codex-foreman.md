# 병렬 개발 조율
> **요약**: [workflow](../development/workflow.md)의 독립 작업 병렬화에만 적용한다. 별도 영속 작업반장은 두지 않고 총괄이 조율한다. [AGENTS](../../AGENTS.md)·[CLAUDE](../../CLAUDE.md).

- 실제 임명·ACK를 받은 담당이 해당 과업의 배정·회수·병합 순서를 관리한다.
- 좁은 파일 범위·선후행·writer·검수자·base·수용조건·반환처를 명시한다.
- 실제 전달·ACK를 확인한다. 미확인/전달 실패를 ACTIVE로 쓰지 않는다.
- writer를 겹치게 두지 않는다. 공용 계약/migration 번호는 열린 PR과 대조한다.
- 자기보고 외에 현재 diff·검사·실화면으로 검수하고 필요하면 독립 검수를 받는다.
- 재작업/다음 작업/병합 판정을 실제 담당에게 전달한다. 관리 ACK는 제품 배정·병합 권한이 아니다.
- 병합~배포는 직렬. 기술 게이트 뒤 사용자 재승인 대기 금지.
- 역사적 NO-GO·큐·lease는 자동 승계하지 않는다. blocker와 재개 조건을 기록하고 독립 작업은 계속한다.

## 에이전트 "배포 성공·200" 오보고 원인 (사후 보고 정확성)
관찰 명령이 `gh run watch … | tail` + `curl 사이트 200` 조합이었는데, ① rtk 요약을 거치며
watch 의 실패 신호가 유실될 수 있고 ② **무중단 설계에선 배포가 빨간색이어도 사이트는 항상
200** 이라 200 은 성공 증거가 못 됨. → **교정: 머지 후 관찰은 반드시
`gh run view <id> --json conclusion` 값(success 문자열)을 명시 확인**하고 그때만 성공 보고.
(사이트 200 은 "다운 아님" 증거일 뿐.)

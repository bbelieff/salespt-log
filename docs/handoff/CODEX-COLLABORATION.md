# 개발 협업·인계
> **요약**: 기존 작업을 보존하고 현재 증거로 이어받는다.
> **관련**: [AGENTS](../../AGENTS.md)·[CLAUDE](../../CLAUDE.md)·[worklog](../worklog.md).

- 메인 읽기 전용, 담당별 전용 worktree 편집.
- 현재 담당 파일·선행조건을 worklog/PR에 선언한다. 공급자 이름·옛 registry로 소유를 추정하지 않는다.
- 파일 동시 쓰기 금지. 공용 계약 별도 검토·선행 병합.
- HANDOFF.md는 존재하고 현재 과업에 필요한 경우만 참고. 자동 필독/복제/수정 대상이 아니다.
- 구현은 독립 범위만 병렬, 병합~배포는 직렬. 현재 head 검사·CI·배포 success·health·live 확인.
- worklog 양쪽 기록·사용자 변경·타인 자원·비밀값 보존.
- 같은 승인 범위의 push/PR/병합/배포 재승인 금지. 새 데이터·비용·권한·외부 발행 범위는 확인.
- 목표/범위·실제 담당/thread·base/head·변경·검사·PR/배포·미완료/다음 행동·위험을 인계한다.
- 증거 없는 실행을 완료로 쓰지 않는다. 과거 큐의 현재 상태는 미확인과 구분한다.

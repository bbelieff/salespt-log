# 대시보드 데이터 디스커버리 (Data Discovery)

> Claude Code가 실제 Google Sheets에서 확인하고 결정해야 할 항목 체크리스트.
> claude.ai prototype에서 가정한 값과 실제 시트의 일치 여부를 검증하는 용도.

## 사용법

각 항목별로:
1. ☐ **Prototype 가정**: claude.ai에서 사용한 값/위치
2. ☐ **확인할 것**: 실제 시트에서 검증해야 할 사항
3. ☐ **결과 기록**: 디스커버리 결과 (실제 셀 위치 / 추가 필요 / 수식 정의 등)

확인 완료 시 `[x]`로 체크.

- [ ] **헤더 SSOT 정의 (Belief 2026-05-07 검증/정정)**: D-day = `(N1 + 57d) − today` 동적 계산
  - ⚠️ 헤더 SSOT 핸드오프 v1의 `+50d`는 잘못 — 6기 검증 결과 `+57d`로 정정

- [ ] **참고**: 시트에 별도 종강총회일 셀이 있더라도 헤더 D-day는 N1 + 57d 동적 계산

## ✅ 디스커버리 완료 기준

이 문서의 모든 항목이 ☑ 체크된 상태에서 React 포팅을 시작하면 안전.

**Belief에게 권장 워크플로우**:
1. 위 문서를 들고 Claude Code에 작업 시작
2. Claude Code가 시트 검증 → 결과를 항목별 [결과] 칸에 기록
3. 디스커버리 결과를 다시 claude.ai prototype에 반영 (필요시)
4. SSOT 문서 갱신 (`data-model.md`, `sheet-structure.md`)
5. 그 후 React 컴포넌트 구현 시작

## 2. 🟡 영업퍼널 단계 재구성 (5단계 → 6단계)

### 2-1. 새 6단계 정의

| # | 단계 | 의미 | 데이터 출처 |
|---|---|---|---|
| 1 | 생산 | 채널별 DB 생산활동량 | 영업관리 E열 (채널별 합계) |
| 2 | **유입** *(신규)* | 유효 DB 등록 | 영업관리 F열 |
| 3 | 컨택진행 | 통화 시도 수 | 영업관리 G열 |
| 4 | **미팅예약** *(컨택성공에서 개명)* | 모든 미팅 약속 (상태 무관) | 영업관리 H열 |
| 5 | **미팅완료** *(미팅에서 개명/재정의)* | 실제 진행 미팅 | 업체관리 J열 상태 = "완료" OR "계약" |
| 6 | 계약 | 계약 체결 | 업체관리 K열 = TRUE 또는 J열 상태 = "계약" |

### 2-2. 단계별 정의 명시

- **미팅예약**: 예약 + 계약 + 완료 + 변경 + 취소 (= 모든 미팅 약속, 업체관리 행 생성 시점)
- **미팅완료**: 완료 + 계약 (= 실제 미팅 진행된 건만, 변경/취소는 제외)

### 2-3. 본격 영업 퍼널 정의
- **본격 시작점**: 유입부터 (생산 X)
- **이유**: 현수막 같은 채널은 생산-유입 사이 손실이 크지만, 이는 "채널 운영 효율"이지 "영업 효율"이 아님. 영업 효율은 유입부터 측정해야 정확.
- **prototype 시각 처리**: 이전엔 생산을 옅게 처리했으나, 사용자 결정으로 **현재는 모든 단계 동일 시각 강도** (Belief 결정: 2026-05-07 후반)

## 4. 🔵 디자인 결정 (의미 함의)

### 4-1. 매출 = 수임비 + 수수료
- **공식**: 총매출 = 총수임비 + 총수수료
- **시트 매핑**:
  - 총매출 = 대시보드 D21
  - 총비용 = 대시보드 E21
  - 영업이익 = D21 - E21
- **메인 배너 표기 위계**: 매출(상위) > 수임비/수수료(하위 분해)

### 4-2. 생산성 지표 4개 정의

| 지표 | 공식 | 의미 |
|---|---|---|
| DB 퀄리티 | 컨택진행 ÷ 유입 | 입구 단계 효율 |
| 컨택숙련도 | 미팅예약 ÷ 컨택진행 | 통화→약속 전환 효율 |
| 미팅숙련도 | 계약 ÷ 미팅완료 | 미팅→계약 전환 효율 |
| 영업생산성 | 계약 ÷ 컨택진행 | **종합 지표** (종착점) |

### 4-3. 전체 전환율 인사이트 기준
- **기준**: 유입 → 계약 (생산이 아닌 유입부터)
- **이유**: 생산은 채널별 효율 차이가 큰 단계이므로 영업 효율 측정에서 제외
- **공식**: `계약 ÷ 유입`
- **prototype 더미값**: 23 ÷ 282 = 8.2%

### 4-4. 매출/비용 박스 비율
- **변경 전**: 3:2 (매출 col-span-3, 비용 col-span-2)
- **변경 후**: **1:1** (grid-cols-2 균등) — 비용 박스 ₩4,800,000이 짤리지 않도록

### 4-5. 디자인 컬러 그라데이션 (생산성 지표)
- **메인 컬러**: indigo (브랜드 blue와 영업생산성 종착 purple 사이 톤)
- **그라데이션**: 입구(옅은 indigo) → 종착(진한 indigo + purple)
  - DB 퀄리티: indigo-300
  - 컨택숙련도: indigo-500
  - 미팅숙련도: indigo-700
  - 영업생산성: gradient indigo-500 → purple-600 (강조 박스)

### 4-6. 섹션 제목 디자인 통일 패턴 (Accent Bar)
- 좌측 `w-1 h-5 rounded-full` 색 막대 + `font-extrabold` 제목
- 메인 섹션: `h-5`, 서브 섹션: `h-4`
- 색 매핑:
  - 영업퍼널 → blue-500 (계약 강조와 일치)
  - 생산성 지표 → indigo-500 (생산성 메인 컬러)
  - 8주차 추이 → slate-500 (시간 추이 톤, 페이지 배너와 같은 슬레이트)
  - 채널별 비용 → red-500 (비용 메인 컬러)

### 4-7. 진행바 끝점 빛나는 SVG 디자인
- 진행바: blue-400 → blue-600 그라데이션
- 끝점: amber 5겹 SVG (외곽 halo + 중간 halo + 메인 dot + 안쪽 빛 + 광택 점)
- 의미: "현재 위치"의 시각적 강조

### 4-8. 영업퍼널 사다리꼴 높이
- **변경 전**: 30px
- **변경 후**: **15px** (절반) — 컴팩트함과 funnel 시각 균형

### 4-9. 콜·지·기·소 도넛 처리
- 도넛 자체에는 포함 X (비용 0이므로)
- **별도 박스로 표시** (단, 결론 표현 X):
  - "100% 순익률" 같은 결론 표현 제거
  - "↓ 아래 별도 표시" 같은 시선 가이드 제거
  - 사실 정보만: 점선 dot + "비용 발생 없음" + 수임비 ₩2,100,000

### 4-10. 영업이익 카드
- 카드 구조: 좌측 `border-l-4 border-blue-500` + 큰 영업이익 금액
- 부연: "영업이익률 61.6%" (매출 정보는 메인 배너로 이동했으므로 카드에서 제거됨)
- **= 동그라미 배지** (매출 +, 비용 − 와 통일된 디자인): `w-4 h-4 rounded-full bg-blue-100 text-blue-600 ＝`
  - 매출 배지: bg-gray-200 text-gray-700 ＋
  - 비용 배지: bg-red-100 text-red-600 －
  - 영업이익 배지: bg-blue-100 text-blue-600 ＝
  - 세 박스의 산술 흐름 (+, −, =)을 시각적으로 통일

### 4-11. 메인 배너 종강총회/수료일 통합 표시 (Belief 결정)
6기 시나리오에서 종강총회 = 수료일 = N1 + 57d = 6/6으로 **같은 날**이 확정되어, prototype에 두 정보를 분리 표시하면 중복.

- 변경 후: 상단 우측 비움 + 하단 우측 "🎓 6/6 종강총회" (통합 표시)
- 이유: 같은 날짜 중복 제거 + "종강총회"가 사용자에게 더 명확한 라벨

### 4-12. 메인 배너 상단 라벨 형식 (Belief 결정 2026-05-07)
PRM 코호트 정보는 시트(`01 영업관리!B3` cohort)에 "6기" 같은 기수만 있고 "PRM" 프로그램명은 없음 → "6기" 표기 제거.
- 변경 전: `6기 (예시) [4주차]`
- 변경 후: `현재 [today] ([요일]) · [N주차] 진행중`
- **동적 부분**: `today` (오늘 날짜 MM/DD), `요일` (한글 한 글자), `N주차` (주차 숫자)
- **정적 부분**: "현재", "진행중", "·"
- prototype 더미: `현재 5/4 (월) · 4주차 진행중`

**디자인 (두 그룹 통일, 제목 수준)**:

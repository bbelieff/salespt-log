### 2. `01 영업관리` 탭 H3:H6 (참고 — 그대로 유지 가능)

영업관리 H3:H6은 별도 "영업효율관리" 영역. 대시보드 통일안과 분리해도 됨:
- H3 컨택>일정 성공률 (`=F4/F3`) = 미팅예약/컨택진행 ← 대시보드 H26 컨택성공률과 동일
- H4 일정>미팅 성공률 (`=F5/F4`) = 미팅완료/미팅예약 ← 보조 지표 (실행률), 4지표에 없음
- H5 미팅>계약 성공률 (`=F6/F5`) = 계약/미팅완료 ← 대시보드 H27 미팅숙련도와 동일
- H6 컨택>계약 성공률 (`=F6/F3`) = 계약/컨택진행 ← 대시보드 H28 영업생산성과 동일

→ **영업관리 H3:H6은 그대로 유지 권장** (영업관리 영역 자체 보조 지표).

### 3. `01 영업관리` 탭 F5 ("미팅 완료") 수식 확인

**중요**: `미팅완료` 정의 변경됨 (계약+완료+취소).

현재 F5 수식이 무엇인지 확인 후, 만약 `완료+계약`만 카운팅 중이면 **취소도 포함**하도록 변경:

```
변경 전 가정: =COUNTIFS('04 업체관리(앱자동작성용)'!J:J, "완료") + COUNTIFS(...J, "계약")
변경 후:     =COUNTIFS('04 업체관리(앱자동작성용)'!J:J, "완료")
              + COUNTIFS(...J, "계약")
              + COUNTIFS(...J, "취소")
```

## 적용 순서

1. **F5 수식 정정** (취소 포함) — 영업관리 탭
2. **B25:B30 확장** (미팅예약 추가) — 대시보드 탭
3. **H25:H29 4지표 재구성** — 대시보드 탭

## 또는 — 시트 손대지 않는 옵션

웹은 **자체 계산** 하므로 (matrix.미팅완료 등 데이터만 있으면 됨), 시트 H25:H29를 그대로 둬도 웹은 정상 동작.

다만 시트 H 컬럼을 직접 보는 사용자가 헷갈릴 수 있으므로 **장기적으로는 통일 권장**.

# 시트 정정 가이드 — 생산성 지표 통일 (2026-05-08, 5지표 최종)

> **수동 작업 가이드** — 사용자가 시트 직접 수정.
> 목적: 시트 H 컬럼 5지표 user spec 통일.

## 결정 (2026-05-08)

**5지표** (대시보드 = 웹 = 시트 통일):

| # | 지표 | 공식 |
|---|---|---|
| 1 | DB 퀄리티 | 컨택진행 ÷ 유입 |
| 2 | 컨택성공률 | 미팅예약 ÷ 컨택진행 |
| 3 | 미팅실행률 | 미팅완료 ÷ 미팅예약 |
| 4 | 미팅숙련도 | 계약 ÷ 미팅완료 (= 영업관리!L) |
| 5 | 영업생산성 | 계약 ÷ 컨택진행 |

**미팅완료 정의** = 계약+완료 (취소·변경 제외). 시트 `01 영업관리!L` 자동 수식 사용 — **시트 F5/L 수식은 그대로 유지** (이미 올바른 정의).

## 1. `01 영업관리` 탭 — 손대지 않음 ✅

L 컬럼 (미팅 완료 수)이 이미 `상태 IN ["계약","완료"]` COUNTIFS — user spec과 일치. 그대로.

## 2. `대시보드(자동작성)` 탭 정정

### 2-1. B25:B30 — 6단계 funnel 확장 (필수)

**현재 (5단계, 미팅예약 누락)**:
| 셀 | 현재 수식 |
|---|---|
| B25 | `='01 영업관리'!F1` (생산) |
| B26 | `='01 영업관리'!F2` (유입) |
| B27 | `='01 영업관리'!F3` (컨택진행) |
| B28 | `='01 영업관리'!F5` (미팅완료) ← F4 건너뜀 |
| B29 | `='01 영업관리'!F6` (계약) |

**변경 후 (6단계, 미팅예약 추가)**:
| 셀 | 새 수식 | 의미 |
|---|---|---|
| B25 | `='01 영업관리'!F1` | 생산 |
| B26 | `='01 영업관리'!F2` | 유입 |
| B27 | `='01 영업관리'!F3` | 컨택진행 |
| B28 | `='01 영업관리'!F4` | **미팅예약** ← 신규 |
| B29 | `='01 영업관리'!F5` | 미팅완료 |
| B30 | `='01 영업관리'!F6` | 계약 |

### 2-2. H25:H29 — 5지표 라벨/수식 정정

**변경 후**:
| 셀 | 새 라벨 (G) | 새 수식 (H) | 의미 |
|---|---|---|---|
| 25 | DB 퀄리티 (유입 → 컨택진행) | `=B27/B26` | 컨택진행 ÷ 유입 |
| 26 | 컨택성공률 (컨택진행 → 미팅예약) | `=B28/B27` | 미팅예약 ÷ 컨택진행 |
| 27 | 미팅실행률 (미팅예약 → 미팅완료) | `=B29/B28` | 미팅완료 ÷ 미팅예약 |
| 28 | 미팅숙련도 (미팅완료 → 계약) | `=B30/B29` | 계약 ÷ 미팅완료 |
| 29 | 영업생산성 (컨택진행 → 계약) | `=B30/B27` | 계약 ÷ 컨택진행 |

### 2-3. `01 영업관리!H3:H6` — 그대로 유지 권장

이 영역은 별도 "영업효율관리" 보조 영역. 대시보드와 분리해도 무관:
- H3 컨택>일정 (`=F4/F3`) ≈ 컨택성공률
- H4 일정>미팅 (`=F5/F4`) ≈ 미팅실행률
- H5 미팅>계약 (`=F6/F5`) ≈ 미팅숙련도
- H6 컨택>계약 (`=F6/F3`) ≈ 영업생산성

→ DB 퀄리티만 없음. 보조 영역으로 유지.

## 적용 우선순위

1. **(필수)** 대시보드 B25:B30 6단계 확장 (B28에 F4 추가)
2. **(필수)** 대시보드 H25:H29 5지표 라벨/수식
3. (그대로) 영업관리 F5/L 수식 — 이미 올바름
4. (선택) 영업관리 H3:H6 — 그대로 유지

## 또는 — 시트 손대지 않는 옵션

웹은 자체 계산하므로 시트 H25:H29 안 건드려도 웹 정상 동작. 시트 H 직접 보는 사용자가 헷갈리지 않게 하려면 통일 권장.

## 탭 개요

**역할**: 계약 1건 = 1행. 계약 후 서류 진행과 분할 수납을 추적.
**자료원**: 일정·계약 탭(업체관리 시트)에서 계약여부=TRUE인 미팅이 트리거 → 자동 row 생성
**1행 단위**: 1계약 (다른 탭들이 1미팅=1행이지만 이 탭은 1계약=1행)

## 일정·계약 ↔ 계약수납 양방향 동기화 규칙

### 트리거: 신규 계약 row 생성
```
업체관리!K(계약여부) = TRUE 변경 시
  → 02 계약수납관리에 신규 row append
  → C(계약일) = 업체관리!D(미팅날짜)
  → D(업체명) = 업체관리!G(업체명)
  → E(수임비) = 업체관리!L(수임비)
  → F(수수료) = 0 (사용자가 추후 입력)
```

### 양방향 수정 (C/D/E)
```
계약수납에서 수정:
  PATCH /api/contracts/:id  
    → 02 계약수납관리!C/D/E update
    → 업체관리 row(같은 미팅 ID) D/G/L도 동기화

일정·계약에서 수정:
  PATCH /api/meeting/:id
    → 업체관리!D/G/L update
    → 02 계약수납관리 row(같은 계약 ID) C/D/E도 동기화
```

### 단방향 (계약수납 전용 — 동기화 X)
- F 수수료
- G~M 7체크
- N~AE 수납 슬롯 (모두)

## 영향 받는 다른 시트 (수식 재설계 필요)

### 01 영업관리 시트
기존: Q~T(승인/수납 집계)가 다른 시트에서 SUMIFS로 끌어옴
변경: `02 계약수납관리` 시트의 Q/W/AC(승인금액) + R/X/AD(수납액) 기준으로 재설계

```
01 영업관리!Q (승인건수) = COUNTIFS('02 계약수납관리'!N/T/Z, "100%", ...)
                          ↑ 일자 기준 필터 (어떤 일자 기준인지 결정 필요)
01 영업관리!S (수납금액) = SUMIFS('02 계약수납관리'!R+X+AD, ...)
```

⚠️ 시트 1열에 합계 행이 없다고 사양에 명시됨. 집계는 모두 영업관리 시트로.

# ADR-0032: 10기 이후 12주 과정

상태: 사용자 승인, 2026-09-16.

## 정책
- 숫자 기수 10 이상은 수강기간·주간목표·누적 통계를 12주로 확장한다.
- 9기 이하와 아레나 등 비숫자 기수는 기존 정책을 유지한다.
- 수강 종료일은 시작일을 포함한 12주 마지막 날이다. 종강총회와 구분한다.
- 11기 이후 총회는 12주차 안의 토요일이다. 10기만 2026-10-25 일요일이다.
- 날짜·기간 계산의 정본은 `lib/config/cohort-dates.ts`다.

## 데이터 보존과 경로
기존 기록·시작일·시트 O2·레지스트리 캐시는 일괄 덮어쓰지 않는다. 기존 기수의 웹 프로필은 시작일과 승인된 정책에서 총회일을 계산한다. 신규 생성은 같은 계산으로 O2를 초기화한다. 따라서 기존 시트의 이전 O2 값과 웹 정책 날짜는 다를 수 있다. 시트는 백업이며 웹의 새 날짜 정책을 제한하지 않는다.

통계는 DB에서 해당 기수 기간을 전달해 계산한다. 12기 이후 신규 기수는 기존 DB 읽기·쓰기 게이트에 포함한다. 기존 10·11기 DB 경로는 유지한다. 시트 물리 상한 `MAX_SHEET_WEEK=10`과 구 기수 기본 `STATS_WEEKS=8`은 변경하지 않는다. 11~12주 기록은 기존 DB overflow 경로를 이용한다. 주간목표는 날짜 키로 저장하며 기존 8주 제한이 없어 보존한다.

## 검증과 복구
9/10/11/미래 기수·아레나, 유효하지 않은 날짜, 12주 포함/13주 제외, 10기 총회 예외, 레거시 기본값을 검증한다. 기존 단위·구조 검사와 빌드 후 배포한다. 코드 되돌림으로 복구하며 학생 기록 삭제나 되돌림은 하지 않는다.

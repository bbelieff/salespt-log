# ADR-0036 — 1024px 미만 하단 탭을 메뉴 서랍(사이드탭)으로

> **📄 이 문서는 무엇인가요?**

## 결정 (belie 2026-11-07)
1. 1024px 미만에서도 메뉴는 사이드탭 하나. 하단 TabBar 는 (app) 셸에서 렌더하지 않는다.
2. 폰은 좌우가 짧으니 닫힌 사이드탭은 **화면에 전혀 보이지 않는다**(화면 밖·invisible). 페이지 배너 맨 왼쪽(로고 아래 줄) 메뉴 버튼으로 연다.
3. PC 는 지금처럼 본문을 밀고(접기·펼치기 유지), 1024px 미만은 **본문 위를 덮는 서랍** — 뒤를 어둡게, 바깥 누르기·Esc·닫기 버튼·다른 화면 이동 때 닫힌다. 서랍은 늘 펼친 모양(아이콘만 접힘은 PC 전용).
4. **손가락 밀기**: 오른쪽으로 밀면 열리고, 열린 채 왼쪽으로 밀면 닫힌다(가로 60px+, 세로의 2배 넘게). 입력 칸·크기 조절 손잡이·왼쪽으로 밀린 가로 스크롤 안·다른 팝업이 떠 있을 때는 열지 않는다. PC 는 무시.
5. 하단 바가 없으므로 `--app-tabbar-height` 는 아래 안전 영역만 남긴다(토스트·「오늘 챙길 일」·새 버전 알림 위치가 따라 내려간다).

## 영향
- 하단 탭의 새 기능 점(앵커 dot)은 사라진다 — 화면 안 NEW 뱃지는 그대로.
- 관리자·트레이너 화면(학생 셸 아님)은 배너 막대 그대로, 메뉴 버튼 없음.
- `components/TabBar.tsx` 의 `NAV_STEPS`(4단계 정의)는 사이드탭이 계속 쓴다.

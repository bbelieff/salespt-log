# ADR-0008 — 탭 라벨 변경 (수납 → 실무/수납)

> **📄 이 문서는 무엇인가요?**
> - **한 줄 요약**: 하단 탭 라벨 `수납`→`실무/수납`(아이콘 코인+$ 유지), 배너 제목도 함께 변경
> - **누가 읽나요**: 개발자
> - **어떤 기능·작업과 연결?**: `components/TabBar.tsx`, `docs/design/prototypes/`, payment 페이지 배너
> - **읽고 나면 알 수 있는 것**: 왜 라벨만 바꾸고 아이콘은 유지하나, 동기화 대상
> - **관련 문서**: `practice-and-drive.md` §4b·부록 A

- **Status**: accepted
- **Date**: 2026-06
- **Supersedes**: 없음

## Context
수납 탭이 이제 실무진행(기관 진행 + 슬롯 ToDo)까지 포함하므로 라벨을 "실무/수납"으로 바꾼다. 단:
- `components/TabBar.tsx`의 5탭(`컨택관리 / 일정·계약 / 캘린더 / 수납 / DB관리`)은 순서·라벨·아이콘 고정. 변경 시 ADR 필요. **대시보드는 하단 탭이 아니라 헤더 "대시보드 ›" 버튼** — 본 변경은 탭 추가 없이 4번째 탭(`/payment`) 라벨만 건드린다(5탭 구조 불변).
- 탭 아이콘은 프로토타입 `calendar-monthly.html`의 하단 nav와 **동기화**되어 있다.
- 라우트·탭 id·딥링크·상태 저장을 깨면 안 된다.

## Decision
1. 하단 탭 **라벨** `수납` → `실무/수납` (표시 텍스트만).
2. **아이콘은 기존 PaymentIcon(코인+$) 그대로 유지** — 변경 없음.
3. 탭 **개수/순서/라우트/key 불변** (`/payment` 그대로).
4. 페이지 **배너 제목**도 `계약수납` → `실무/수납` (별개 요소지만 함께 변경). 배너의 시트참조 텍스트는 제거(Plan 부록 D).
5. 프로토타입 `calendar-monthly.html`의 탭바 라벨도 동기화.

## Alternatives considered
- **아이콘도 변경(체크리스트형 등)**: 컴포넌트 SVG + 프로토타입 동기화 + 추가 검토 필요, 사용자도 연속성 위해 유지 희망 → 기각(유지).
- **새 탭 추가(6탭)**: 5탭 고정 방침·모바일 하단 폭 → 기각.

## Consequences
- (+) 최소 변경(라벨 1단어 + 배너). 딥링크/상태 안전. **5탭 근본 불변** — 초기 "탭 구조 흔들림" 우려는 해소됨.
- (절차) `TabBar.tsx` 라벨 + 프로토타입 라벨 2곳 동기화. 아이콘 미변경이라 SVG 작업·추가 ADR 불필요.

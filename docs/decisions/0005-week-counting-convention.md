# ADR-0005 — 주차 카운팅 컨벤션 + 종강총회일 계산

> **📄 이 문서는 무엇인가요?**
> - **한 줄 요약**: O1(수강시작일) 의 의미와 종강총회일(O2) 계산 규칙을 박제 — 6기 legacy(+57) vs 7기+ 현행(+50).
> - **누가 읽나요**: 개발자 + 운영자 (시트 셋업)
> - **어떤 기능·작업과 연결?**: `lib/repo/sales.ts`(weekIndexOf/salesRowFor/readGraduation), `lib/service/me.ts`, 시트 O1/O2 셀
> - **읽고 나면 알 수 있는 것**: O1 에 무슨 날짜를 넣나? 종강총회는 며칠 뒤인가? 6기와 7기는 왜 다른가?
> - **관련 문서**: `docs/domains/data-model.md`, `docs/playbooks/setup-sheets.md`

- **Status**: accepted
- **Date**: 2026-05-14
- **Supersedes**: 없음 (기존엔 ADR 없이 코드 주석으로만 존재 — 그게 문제였음)

## Context

종강총회일 offset 이 코드베이스에 **세 값으로 혼재**했다:
- `lib/service/me.ts` `GRADUATION_OFFSET_DAYS = 57`, `lib/repo/sales.ts` 주석 `=O1+57`, `data-model.md` `+57`
- `CLAUDE.md` §2.5 / `docs/domains/api-spec.md` `+55일`
- 실제 운영: 7기는 `+50`

원인: **6기와 7기의 주차 카운팅 방식이 다름**. 6기까지는 "한 주의 끝" 기준, 7기부터 "한 주의 시작" 기준으로 바뀌었는데 코드/문서가 이를 반영 못 하고 매번 다른 숫자가 박혔다.

운영 실측 (2026-05-14 사용자 확인):

| 기수 | 시트 O1 | 1주차 강의시작 | 종강총회 (O2) | O2 − O1 |
|------|---------|---------------|--------------|---------|
| 6기  | 4/10    | 4/18          | 6/6 (금)      | **+57** |
| 7기  | 5/15    | 5/15          | 7/4 (토)      | **+50** |

## Decision

### 1. O1 = 시트의 "1주차 블록" 기준일

`weekIndexOf(date, O1) = floor(diffDays(date, O1) / 7) + 1` — **코드 불변**. 주차
계산은 항상 O1 을 기준으로 한다. 6기/7기 차이는 **O1 에 무슨 날짜를 넣느냐**로
전부 흡수된다 (코드에 기수 조건부 분기 불필요).

### 2. 7기+ (현행 모델) — "한 주의 시작" 카운팅

- **O1 = 1주차 강의시작일 (금요일)**. 시트 "1주차" 블록 = 실제 content 1주차.
- 각 주차 = 금~목 7일. 1주차 시작 + 7×(n−1) = n주차 시작.
- 8주차 시작 = O1 + 49 (금). **종강총회 = 8주차 시작 다음날 (토) = O1 + 50**.
- 시트 O2 수식: **`=O1+50`**.
- 예) 7기: O1 = 5/15(금) → 8주차 시작 7/3(금) → 종강총회 7/4(토).

### 3. 6기 이하 (legacy 모델) — "한 주의 끝" 카운팅 — **변경 없음, 보존만**

- O1 이 실제 강의시작일보다 ~1주 앞서 세팅됨. 시트 블록 라벨이 2주차~8주차
  (실 content 1~7주). `weekIndexOf(강의시작일, O1)` 가 2 를 반환 → "2주차" 블록.
- 종강총회 = O1 + 57. 시트 O2 수식: `=O1+57`.
- 예) 6기: O1 = 4/10 → `weekIndexOf(4/18, 4/10) = 2` → 4/18 데이터가 "2주차"
  블록(row 44)에 들어감. 종강총회 6/6.
- **6기 시트는 이미 이 방식으로 셋업·운영 중. 절대 건드리지 않는다.**

### 4. `GRADUATION_OFFSET_DAYS`

`lib/service/me.ts` 의 이 상수는 **테스트 fixture 전용** (production `loadMe()` 는
시트 O2 를 직접 읽음). **현행(7기+) 모델 기준 `50` 으로 고정**. 6기 legacy 값(57)
은 이 상수로 표현하지 않는다 — 6기 시트의 O2 가 직접 진실.

## Consequences

- ✅ `weekIndexOf` / `weekStartOf` / `salesRowFor` **코드 변경 0** — O1 값만 올바르면 됨.
- ✅ 종강총회일 진실원천 = **각 시트의 O2 셀** (코드는 읽기만).
- ⚠️ **7기 시트 셋업 시 O2 = `=O1+50` 필수** (이전 템플릿 `=O1+57` 은 7기엔 틀림 → 7/11 로 7일 밀림).
- ⚠️ 이미 만든 7기 시트가 `=O1+57` 이면 → O2 를 `=O1+50` 으로 수동 수정 필요.
- 6기 시트는 그대로 (O1=4/10, O2=O1+57).
- `docs/playbooks/setup-sheets.md` 의 O2 수식 안내 갱신 필요 (PR #191 이 해당 파일
  전면 개정 중이므로 #191 머지 후 후속 반영).

## Out of scope

- **편집 가능 마감일** (`편집유예 기간`, 현재 CLAUDE.md `수강시작일+69일`) 은 본 ADR
  에서 재정의하지 않는다. 7기+ 종강총회가 +50 으로 바뀜에 따라 편집유예 마감도
  조정이 필요할 수 있으나, 사용자가 명시 재정의하지 않아 별도 결정으로 남긴다.

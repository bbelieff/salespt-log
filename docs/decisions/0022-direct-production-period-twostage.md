## 맥락

직접생산은 기간 집행 → 종료 후 생산수 확정이다. 단일 `날짜` 모델로는 기간·상태를 못 담았다. 부가세 표준(ADR-0021)에 따라 예산도 ex-VAT 저장 + 부가세여부 플래그가 필요하다.

## 결정

1. **I:O 재배치**: `시작일(I)·종료일(J)·소재(K)·기간예산(L)·생산개수(M)·부가세여부(N)·기타(O)`. 구 스페이서 O 흡수, 현수막 `P:V` 위치 불변. 구 `개당단가(M 수식)`는 **시트 저장 제거** → 화면 계산(예산÷개수).
2. **2단계·상태 파생**: 별도 상태 컬럼 없이 `생산개수` 빈/0=생산중, 채움=완료. ① 생산 시작=시작/종료일·소재·예산 기록(생산개수 빈). ② 완료=생산개수 입력.
3. **집계 기준 = 종료일 & 완료**: `productionCountFor(직접생산)` = `종료일==date && 생산개수>0` Σ생산개수. 생산중은 E 미반영. 비용(기간예산)은 시작 시 반영.
4. **예산 ex-VAT**: 입력 예산+부가세토글 → `기간예산 = 예산 ÷ (포함?1.1:1)` 저장(ADR-0021). 부가세여부 N 저장.
5. **전환 lazy·무블로킹**: read 가 J(종료일=날짜) 유무로 신규/구 레이아웃 판별해 흡수(구는 시작=종료=날짜). 쓰기는 신규 레이아웃 기록. 일괄 시트 마이그레이션 없음(편집 시 점진 이전).

## 대안 / 기각

- **기간 텍스트 1컬럼("시작~종료")**: 파싱 필요·정렬/집계 취약. 정식 날짜 2컬럼이 안정(스페이서 O 흡수로 공간 확보).
- **상태 컬럼 추가**: 공간 부족 + 생산개수 유무로 충분히 파생.

## 결과

- XP(`r.production`)가 집계 기준 변화(완료 시점)로 달라질 수 있음 — 가중치 불변, 회귀만 확인(R7).
- `data-model.md`/`sheet-structure.md` 동기화. 단위테스트: `productionCountFor` 직접생산(종료일&완료).
- 전환 판별은 J 가 날짜인지로 판단 — 소재가 날짜 형식이면 오판 가능(광고 소재명은 날짜 아님 → 실무상 안전).

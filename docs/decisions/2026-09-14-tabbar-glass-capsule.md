# 하단 유리 바·원형 캘린더·헤더 역할 토글

상태: 사용자 최종 선택 및 배포 승인 (2026-09-14). 파일명은 검토 이력을 보존한다.

캡슐 비교 후 사용자는 작고 낮게 돌출된 원형을 최종 선택했다. 기존 52px 불투명 원과 큰 그림자를 44×44px 유리 원으로 대체한다. 흰색 45% 배경, 60% 테두리, 약한 내부 빛과 그림자, translateY(-8px)를 적용한다. 선택 상태는 amber 틴트와 amber700 아이콘·글씨로 표시한다. 라벨 아래 여백을 유지한다.

바는 흰색 32%, blur(20px), saturate(180%)로 표현한다. 바와 본문 예약 공간은 같은 높이 토큰을 사용한다. 블러 미지원 및 투명도 감소 설정에는 불투명 배경을 제공한다. 기존 ADR-0019/0027의 4+1 순서·라우팅·아이콘·STEP·미저장 가드를 유지한다.

역할 선택은 시각 높이 26px, 터치 높이 44px의 연결 세그먼트 토글이다. 대시보드 버튼과 같은 red50/red200/red700 색상을 사용한다. canStudent && canTrainer 조건과 busy, 대리접속 aria-pressed, 전환 API·가드를 유지한다. 트레이너 권한은 로그인 계정의 활성 트레이너 자격을 따른다.

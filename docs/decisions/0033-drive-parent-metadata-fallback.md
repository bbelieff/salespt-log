# ADR-0033: 등록 시트의 누락된 Drive 부모 메타데이터 보완

- Status: accepted
- Date: 2026-09-24
- Scope: 일반 기수 Drive 연결. 사용자 요청: 12기 이후에도 부모 메타 누락으로 자동 연결이 실패하지 않도록 수정.
- Supplements: ADR-0007, ADR-0015. 기수별 고정 ID 또는 학생 이름 검색 없음.

## 근거

운영 읽기 조사에서 앱 서비스계정은 등록 시트와 그 부모·피드백 폴더에 접근할 수 있지만 시트 `parents` 필드는 누락됐다. 같은 등록 시트를 기존 관리자 OAuth로 조회하면 부모를 확인할 수 있었다. 따라서 `parents` 부재만으로 폴더 미공유를 단정하면 안 된다.

## 결정

1. 인증된 사용자의 서버 등록 시트에 대해 서비스계정으로 먼저 확인한다.
2. 유효한 시트의 부모 정보가 없을 때만 기존 관리자 OAuth로 **동일 시트의 메타데이터 GET**을 수행한다. 요청자가 전달한 임의 시트 ID, 전역 검색, 권한 변경, 파일 생성·이동은 허용하지 않는다.
3. 확인된 부모의 직계 자식만 서비스계정으로 검색한다. 유일한 피드백 폴더이며 앱이 실제 조회할 수 있어야 연결한다. 불완전·중복·시간 초과 결과는 추측하지 않는다.
4. 저장된 연결은 접근 가능하면 재사용하며, 검색 실패로 기존 연결을 삭제하지 않는다.
5. DB 읽기 환경에서는 연결정보를 원자적으로 저장하고 완료된 후 캐시를 무효화한다. DB 실패를 연결 성공으로 보고하지 않는다.

ADR-0015의 관리자 OAuth 사용 범위에 위 2번의 제한된 읽기만 추가한다. 새 OAuth 스코프·자격증명·Drive 공유 권한은 만들지 않는다. 앱 서비스계정의 실제 폴더 접근 권한은 계속 필요하다.

## 한계·되돌리기

관리자 토큰 만료, 실제 접근 권한 부족, 폴더 미생성·중복은 구분해 안내한다. 모든 외부 오류를 없앤다고 보장하지 않는다. 코드 PR을 revert하면 이전 알고리즘으로 복귀하며 저장된 연결정보는 유지된다.

# ADR-0037 · STEP 2 = DB관리 (1.5·2 통합, 2026-11-07)

## 상태
채택. ADR-0019·0027 의 STEP 2 라벨(「컨택관리」)과 DB관리시트를 1.5 로 끼운 배치를 대체한다. 4+1 하단 구조·STEP 배지·색은 그대로.

## 맥락
DB관리시트(1.5)가 컨택관리(2)의 일을 대부분 하고 있다 — 최근 6주(전 기수) 매입DB 유입 503건 중 299건(59%)이 시트에서 자동으로 잡혔다. 반면 현수막·콜지기소·직접생산은 시트 DB 가 0건이라 컨택관리의 숫자 입력이 아직 필요하다. belie: 계약 전 단계는 「고객」이 아니라 「DB」다 — 이름에 고객을 쓰지 않는다.

## 결정
- **STEP 2 이름 = 「DB관리」.** 폰 하단 탭·PC 왼쪽 메뉴의 STEP 2 를 누르면 DB 목록(/db-sheet). DB 목록·일별 기록 어디서든 STEP 2 가 켜진다. STEP 1.5 메뉴·배지는 없앤다.
- **DB관리 = [DB 목록 | 일별 기록] 두 탭**(`DbManagementTabs`). 옛 컨택관리 화면은 「일별 기록」(기능 그대로: 주차·채널·숫자·저장·미팅·기록 옮기기).
- **DB 한 줄의 단계 칸**: 1.5 = 「STEP 2 · 컨택 전」(미컨택·부재·재통화 등), 2 = 「STEP 2 · 컨택 완료」(미팅예약·컨택 후 거절). 내부 키(1.5·2)와 정렬은 그대로 둔다.
- **화면 문구의 「STEP 2」**(일별 숫자를 뜻하던 말) → 「일별 기록」. 「DB관리시트」 → 「DB 목록」/「DB관리」.
- **대시보드 「오늘 챙길 일」**: 1.5·2 행을 STEP 2(DB관리) 한 행으로. 첫 연락·재연락은 kind 로 나뉜다.
- **주소는 그대로**(/db-sheet, /contact) — 즐겨찾기·알림·주간목표 링크 보존.
- **DB 전환 전 기수**(DB 목록 없음): DB 목록 API 가 `code: "unsupported"` 로 답하면 화면이 일별 기록으로 바로 보낸다.

## 그대로 두는 것
- 숫자 계산·저장 경로, 시트 미러, 일별 기록의 입력 규칙(ADR-0020·0024·0025·0029).
- 앱 「새소식」 과거 글, 완료된 계획·작업 기록의 옛 이름(역사 기록).
